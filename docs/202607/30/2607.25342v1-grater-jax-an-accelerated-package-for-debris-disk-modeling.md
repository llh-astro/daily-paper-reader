## 摘要
GRaTer-JAX是一个用于对碎片盘（恒星周围的尘埃盘，为行星系统的形成、结构和演化提供重要线索）建模的Python软件包。GRaTer（用于正则化拟合的环形、轴对称、光学薄尘埃盘生成器）是一个最初用于生成和拟合光学薄、轴对称尘埃盘模型的碎片盘建模框架。JAX是一个用于高性能计算的Python软件包，它实现了即时编译和自动微分，能够显著加速正向建模工作流程。GRaTer-JAX提供了比以前工具更强大、更高效、更稳健的碎片盘建模框架。其基于JAX的后端提供了数量级的加速和分析梯度，而其直观且可扩展的API将正向建模、优化和推理统一在单个工作流程中。结合对其磁盘模型的关键补充，它能够进行更高级的碎片盘建模，使得以前计算上不可行的研究（例如通过散射相位函数探索额外的形态参数和磁盘组成）成为可能。

## Abstract
GRaTer-JAX is a Python package for modeling debris disks, disks of dust around stars that pro- vide important clues about the formation, structure, and evolution of planetary systems. GRaTer (Generator of Ring-like, axisymmetric, optically Thin dust disks for regularized fitting) is a debris disk modeling framework originally developed for generating and fitting models of optically thin, ax- isymmetric dust disks. JAX is a Python package for high-performance computing that implements just-in-time compilation and auto-differentiation, enabling significant speedups in forward modeling workflows.   GRaTer-JAX delivers a more powerful, efficient, and robust debris disk modeling framework than previous tools. Its JAX-based backend provides orders-of-magnitude speedups and analytic gradients, while its intuitive and extensible API unifies forward modeling, optimization, and inference within a single workflow. Combined with key additions to its disk model, it is capable of more advanced debris disk modeling, enabling research that was previously computationally impractical such as explorations of additional morphological parameters and disk composition via scattering phase functions.
