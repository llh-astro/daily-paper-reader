## 摘要
对哈密顿动力学的机器学习推动了对哈密顿神经网络（HNNs）的日益增长的兴趣，这类网络将哈密顿运动方程编码到学习架构中。尽管取得了进展，但这些网络能否预测训练数据中不存在的动力学机制仍属未知，尤其是在观测参数区间之外出现的广阔混沌海。我们使用参数感知的随机特征哈密顿神经网络（RF-HNN）来研究这一问题。仅用少数控制参数值下以不变环面为主导的数据进行训练，RF-HNN能够预测在未见参数值下的自主长时间动力学，此时混合相空间发展并出现混沌区域，而训练或模型选择中均未使用该机制的数据。该方法在四个二自由度哈密顿族中得到验证，包括Hénon-Heiles系统。通过庞加莱截面几何和有限时间李雅普诺夫指数，我们表明RF-HNN再现了规则结构的破裂以及混沌区域的出现和增长，而具有相同哈密顿结构的常规训练HNN则保持过于规则。这些结果表明，决定参数外推的并非仅仅是哈密顿结构，而是拟合哈密顿量在控制参数中的延续方式。据我们所知，这是首次证明学习到的哈密顿量能够从主要规则动力学定性外推到训练中不存在的广阔混沌海。

## Abstract
Machine learning of Hamiltonian dynamics has driven growing interest in Hamiltonian neural networks (HNNs), which encode Hamilton's equations of motion into the learning architecture. Despite this progress, it remains unknown whether such networks can predict dynamical regimes absent from their training data, in particular the broad chaotic sea that emerges beyond the observed parameter interval. We address this question using a parameter-aware random-feature Hamiltonian neural network (RF-HNN). Trained using data from only a small number of control-parameter values at which invariant tori dominate, the RF-HNN predicts autonomous long-time dynamics at unseen parameter values where mixed phase space develops and chaotic regions expand, with no data from that regime used in training or model selection. The method is demonstrated across four two-degree-of-freedom Hamiltonian families, including the Hénon-Heiles system. Using Poincaré-section geometry and finite-time Lyapunov exponents, we show that the RF-HNN reproduces the breakup of regular structures and the emergence and growth of chaotic regions, whereas conventionally trained HNNs with the same Hamiltonian structure remain too regular. These results show that what decides parameter extrapolation is not Hamiltonian structure alone but how the fitted Hamiltonian continues in the control parameter. To our knowledge, this is the first demonstration that a learned Hamiltonian can qualitatively extrapolate from predominantly regular dynamics into a broad chaotic sea absent from training.

## 一、核心问题与整体含义（研究动机与背景）

近可积哈密顿系统展示了一条研究最透彻的通往混沌的经典路径：随着扰动/控制参数增大，KAM环面逐渐破碎，共振层展宽并重叠，初始的薄混沌层扩展为主导能量壳的广阔混沌海，形成规则运动与混沌运动共存的混合相空间。关键在于，当调控哈密顿量未知、需从数据重构时，机器学习模型能否预测训练数据中不存在的动力学机制——特别是训练参数区间之外涌现的混沌海滨？

**研究背景**：
- 哈密顿神经网络（HNNs）通过构造标量哈密顿函数并利用哈密顿方程生成向量场，天然保持学习能量的守恒与相空间体积守恒
- 已有研究表明 HNN 能复现训练数据覆盖条件下的有序与混沌行为，以及通过参数感知拓展到训练集外的控制值——但这些先前工作的训练数据本身已包含混沌轨道，只是在复现训练中已存在的机制，而非"外推"到质的新机制
- 储层计算（reservoir computing）的研究显示学习模型可以跨越动力学机制，但尚未用于哈密顿系统从规则到混沌的定性外推

**核心问题**：一个只在规则运动主导的参数区间训练的学习哈密顿量，能否自主地、无需该区间任何数据地外推出混沌在当前参数区间之外的涌现与增长？论文的回答是**肯定**的——通过参数感知的随机特征哈密顿神经网络（RF-HNN）。

这一发现的深层含义是：**决定参数外推成败的不仅仅是哈密顿结构本身，而是拟合哈密顿量如何随控制参数向区间外延续**。这是一个"外推动力学机制"而非"学习能量守恒"的问题——两个模型都可以精确保持哈密顿结构，却产生完全不同的带外动力学行为。

## 二、方法论

### 核心思想
与常规端到端训练的 HNN 不同，RF-HNN 将哈密顿量表示为**固定随机特征层 + 线性读出（ridge regression）**的形式。关键设计：

1. **参数感知**：控制参数 c 通过专用的参数通道输入网络，使模型学习整个参数族而非单一系统
2. **随机特征架构（两隐藏层）**：
   - `ϕ₁(z, c) = σ(Wz·z + wc·c + b₁)`
   - `ϕ₂(z, c) = σ(W·ϕ₁(z, c) + b₂)`
   - `Ĥ_β(z, c) = βᵀ·ϕ₂(z, c)`
   - 其中状态权重 Wz、控制权重 wc、第二层矩阵 W 和偏置 b₁、b₂ 只采样一次、固定不变；**仅 β 通过岭回归拟合**
3. **闭式解训练**：
   - 通过链式法则解析计算特征雅可比矩阵 ∂zϕ₂，使向量场拟合变成线性回归问题
   - 解：β = (AᵀA + αI)⁻¹Aᵀf，不需要反向传播，一次闭式求解即可完成训练
4. **超参数优化**：随机特征尺度（sz, sc, g2）、网络宽度 N 和正则化系数 α 通过贝叶斯优化（Optuna，每个激活函数 100 次试验）在训练区间内的验证控制点上进行选择，超参数优化不使用任何外推区间数据
5. **哈密顿结构保证**：由 Ĥ_β 通过哈密顿方程生成自主流，学习能量和相空间体积守恒由构造保证

### 核心技术细节
- 训练状态在固定能量壳 E₀ 上**独立采样**（而非从轨迹提取）：从矩形提议框均匀采样 (x,y)，拒绝势能 V(x,y;c) ≥ E₀ 的点，剩余能量随机分配动量方向
- 时间积分统一采用四阶龙格-库塔法，时间步长因族而异（0.04–0.05）
- 三种激活函数（tanh、GELU、softplus）各做 100 次贝叶斯优化，以训练区间内验证控制点上的向量场 RMSE 为选择准则

## 六、主要结论与发现

1. **RF-HNN 成功外推混沌涌现**：仅在规则运动主导的参数区间训练后，RF-HNN 在未见控制值下定量复现了混沌海的出现与增长。在有界族的最大外推控制点 μ=1.5，RF-HNN 占据面积 44.06 单元 vs 真值 43.86，λ_T = 0.271 vs 真值 0.263
2. **MLP-HNN 无法外推**：即使保持哈密顿结构，单网络和 20 网络集成在有界族最大外推点占据 32.55 和 26.86 单元（真值 43.86），λ_T 仅 0.066 和 0.057（真值 0.263），显著过于规则
3. **集成无法修复偏差**：集成降低了成员间方差，但无法消除外推哈密顿量共有的"过于规则"偏差
4. **非线性参数延拓成功**：有界族中哈密顿量依赖 μ² 而网络接收 μ，RF-HNN 仍能正确外推，表明模型学会了非线性参数依赖关系
5. **跨系统泛化**：四个不同对称性/耦合/约束类型的哈密顿族上一致成功，结果不局限于 Hénon-Heiles 特定参数化
6. **决定性因素**：参数外推能力取决于拟合哈密顿量在控制参数中的延续方式，而非哈密顿结构本身

## 七、优点

1. **首次展示规则→混沌的定性外推**：据作者所述，这是首个学习哈密顿量从规则动力学训练数据定性外推到混沌海的演示
2. **训练效率极高**：闭式岭回归替代迭代优化，300 次超参数搜索试验开销可控；每次训练无需反向传播
3. **对哈密顿结构的外推归因清晰**：通过对比两种都保持哈密顿结构的模型，将差异精确归因于"拟合哈密顿量的控制参数延拓方式"而非"是否具有守恒结构"，因果论证严密
4. **诊断体系完备**：占据面积 + Chamfer 距离 + 有限时间李雅普诺夫指数的三重评估，分别捕捉面积、几何和动力学不稳定性，能适应混沌轨迹快速去相关的特性；三者的一致性增强了结论可信度

6. **验证充分**：插值测试、架构扫描、多种子统计、不同积分方案的一致性检验等，多层级验证确保了结果的稳健性
