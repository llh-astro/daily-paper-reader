## 摘要
通过对单个太阳能电池在老化0、90、280、480分钟时已发表测量特性的逆向建模，分析了卤化铅钙钛矿太阳能电池的退化。我们采用机器学习来推断材料参数值的分布，从而得出与测量变化相关的物理机制。贝叶斯参数估计与使用IonMonger代码结合光学模型的漂移扩散模拟相耦合。我们通过模型输入参数的变化准确复制了器件性能随老化时间的测量变化。我们的关键结果是，退化受到移动离子浓度和扩散系数的相关变化以及高移动离子浓度下界面复合的影响。这项研究展示了机器学习与模拟相结合可靠解释实验结果的能力，而如果仅使用手动探索输入参数空间的模拟模型，这一任务是有问题的。

## Abstract
Degradation in lead halide perovskite solar cells is analysed by inverse modelling of published measurements of characteristics of a single solar cell at ages 0, 90, 280, 480 minutes. We employ machine learning to deduce distributions of material parameter values and hence the physics linked to measured changes. Bayesian parameter estimation is coupled with drift diffusion simulations using the IonMonger code combined with an optical model. We accurately replicated measured changes in device performance with age through variations in model input parameters. Our key result is that degradation is influenced by correlated changes in the concentrations and diffusion coefficients of mobile ions and by interface recombination at large mobile ion concentrations. This study demonstrates the power of machine learning combined with simulations to reliably interpret experimental results, a task which is problematic if using simulation models with only manual exploration of the input parameter space.

## 2. 论文提出的方法论

**核心思想：**

将贝叶斯推断（Metropolis-Hastings MCMC方法）与基于物理的漂移扩散仿真（IonMonger）及光学模型（RayFlare转移矩阵方法）耦合，对实验JV扫描数据进行逆向参数估计，获取与实验一致的材料参数后验分布，从而揭示退化相关的物理机制。

**关键技术细节：**

1. **物理仿真模型（IonMonger）**
   - 一维漂移扩散模型，模拟三层平面PSC中电子、空穴和单种离子空位（卤化物）的运动。
   - 能够描述JV滞后、反转滞后、阻抗谱等PSC特有现象。
   - 电荷载流子产生分布由RayFlare光学模型（转移矩阵法TMM）计算，而非IonMonger默认的Beer-Lambert分布。
   - 光学谱覆盖AM1.5 100 mW/cm²太阳光谱，并施加常数乘子Gadj = 1.184使模拟与实测Jsc匹配。

2. **贝叶斯参数估计（BPE）**
   - 采用Metropolis-Hastings MCMC采样，根据贝叶斯公式推导参数后验分布p(θ|ym)。
   - 测量结果ym为45维向量：9个扫描速率下的Jsc、Vocr、Vocf、ηr、ηf。
   - 似然函数采用多元正态分布，通过加权均方误差（WMSE）计算，Jsc和Vocf项的权重设为2。
   - MCMC超参数：σstep = 0.1，ρ调整使接受率维持在0.20-0.31，链长400步×40条链，丢弃前一半作为burn-in。

3. **参数选择策略**

   - 发现τn、τp、dE、dH后验接近均匀分布（不收敛、无相关、无趋势），从BPE中剔除并固定为常数值（τn = τp = 2×10⁻⁷ s，dE = dH = 3×10²² m⁻³）。
   - 核心BPE聚焦6个参数：N0、DI、vnE、vpE、vnH、vpH。

4. **模型设置**
   - 器件结构：ITO/PTAA/Perovskite/C60/BCP/Cu（p-i-n倒置结构）。
   - 钙钛矿组成：Cs₀.₀₅(FA₀.₈₃MA₀.₁₇)₀.₉₅Pb(I₀.₈₃Br₀.₁₇)₃，带隙1.63 eV。

## 6. 论文的主要结论与发现

1. **移动离子密度N0随老化显著增加：** 从0分钟的3.76×10²¹ m⁻³增加到480分钟的8.70×10²³ m⁻³（约200倍），与Thiesbrummel等人的BACE测量结果一致。

2. **移动离子扩散系数DI随老化显著降低（新发现）：** 从0分钟的2.68×10⁻¹³ m²/s降至480分钟的7.01×10⁻¹⁵ m²/s（约40倍），Thiesbrummel等人未报道DI的老化依赖性。

3. **N0与DI之间存在强幂律相关关系（核心新发现）：** 老化过程中N0和DI的对数关系呈近似线性（斜率≈-0.8），意味着离子电导率（∝N0×DI）的变化远小于单个参数的变化。这源于JV结果对离子电导率的敏感性远高于对N0或DI单独变化的敏感性。

4. **界面复合速度对退化的影响：** vnH（HTL-钙钛矿界面的电子复合速度）随老化增加（2.5→16.5 m/s），且仅在高N0值下才对JV曲线产生强烈影响——因为高离子浓度屏蔽内建电场后，载流子分布更均匀，HTL界面处电子浓度升高，放大了界面复合的作用。

5. **退化是多个参数协同变化的结果：** 仅改变N0无法完全解释实验JV数据——同时降低DI修正了扫描速率错位，进一步改变界面复合速度才能同时匹配Jsc、效率和滞后行为。

6. **BACE测量局限性：** Thiesbrummel等人对BACE在N0>2×10²² m⁻³时的灵敏度限制的担忧是有道理的，但BPE结果与BACE值仍保持定性一致。

7. **PL结果不能完全复现：** 模拟只能产生0.012 eV的QFLS-Voc差距，远小于实验报告的>0.1 eV；且模拟中QFLS和Voc都随老化下降，而实验显示QFLS上升。排除了N0、DI和四个界面复合速度的组合作为唯一原因，暗示还存在其他未建模的因素（如卤化物偏析、能带偏移变化等）。

## 7. 优点

1. **方法论创新性强：** 将贝叶斯推断与成熟的物理仿真耦合，解决了高维参数空间下手动探索不可行的问题，且能同时提供参数估计和不确定度量化。

2. **参数的关联性分析：** 通过联合后验分布揭示了N0与DI之间的强相关关系（“脊线”结构），这种关联信息是传统点估计方法无法提供的，对理解退化机制具有重要价值。

3. **系统性的参数筛选策略：** 先纳入较宽参数集（10参数），再通过后验分布特征剔除不敏感参数，避免了先验假设的主导，确保了核心分析的聚焦性。

4. **多层次验证：** BPE结果与独立BACE实验测量交叉对比（N0），通过灵敏度分析（图A.7）清楚展示了各参数的作用机制和因果链条。

5. **光学建模改进：** 使用TMM光学模型替换简单的Beer-Lambert近似，更准确反映器件中的光吸收分布，提高仿真物理可靠性。

6. **物理洞察深刻：** 对N0-DI相关性给出了基于Surface Polarisation Model理论的物理解释（离子问题与载流子问题近似解耦，时间响应由离子问题主导）。

7. **谨慎的结论态度：** 对模型无法解释的PL实验结果部分如实报告并分析可能原因（卤化物偏析、器件间差异、界面能带对齐变化等），没有过度声称模型能解释所有现象。

## 8. 不足与局限

**实验覆盖方面：**
- 仅分析了一个器件、一种器件架构（p-i-n倒置结构）、一种钙钛矿组分（三阳离子混合卤化物）的数据。退化机制在不同器件体系（如n-i-p正置结构、无传输层结构）中可能不同。
- PL实验与JV扫描实验可能使用了不同器件，老化条件也可能不同，导致参数不对应，影响PL模拟与实验对比的准确性。

**方法与模型局限：**
- IonMonger仅模拟单种移动离子物种。实际器件中可能同时存在多种缺陷种类（碘空位、溴空位、阳离子空位等），BPE估计的N0和DI可能是多种缺陷的聚合平均值，无法区分各物种的独立贡献。
- 模型未考虑卤化物偏析（phase segregation）——这已被证明在相似时间尺度（<1000分钟）内会在混合卤化物钙钛矿中发生，并显著影响PL结果。
- 未建模PFN-Br和BCP界面层，也未考虑可能的界面化学变化或能带偏移变化。
- 光学模型中使用了相近但非完全相同的器件材料的光学数据（来自其他论文），并施加了人为的Gadj乘子修正，引入一定的模型偏差。

**结果验证方面：**
- 没有通过预测后续时间点（如600或1000分钟）的实验数据来验证模型的外推预测能力。
- 没有独立的测试数据集来检验方法对未见数据的泛化能力。

**计算效率与实用性：**
- MCMC方法需要数万次仿真运行，计算成本较高。论文没有报告具体耗时，对于需要实时监测（“数字孪生”愿景）的场景，当前计算速度仍不足以支持实时更新。

**方法与对比不足：**
- 没有与其他参数反演方法（如基于梯度的方法、全局优化算法、其他ML技术）进行基准对比，无法量化BPE方法的相对优势。

**结论局限性：**
- N0-DI幂律关系的物理机制尚未完全阐明——论文没有给出为什么老化会导致N0增加而DI降低的微观机制解释；可能的新缺陷产生、缺陷种类变化（如从浅能级到深能级）等可能性没有得到深入讨论。
- 对界面复合速度变化的微观起源（是界面化学退化、能带对齐改变还是新界面态形成）未作深入探讨。
