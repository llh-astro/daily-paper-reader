## 摘要
从数据中符号化发现控制方程不仅受算法设计和数据量的限制，还受吸引子几何的限制：长期动力学允许恢复什么。在Lorenz-84上使用系统内设计，其中一个强迫参数驱动不动点、极限环和混沌状态，而控制方程和库保持不变，我们表明单一数值$λ_{\min}(M)$——不变测度矩矩阵的最小特征值——为稀疏回归（SINDy）和进化符号回归（PySR）设定了可辨识性上限。该值源自Birkhoff遍历定理，并在任何运行之前从短参考轨迹中获得，$λ_{\min}(M)$衡量吸引子覆盖函数空间的完整程度：当它趋于零时，任何算法（无论是稀疏的还是组合的）都无法恢复；随着它增长，两种算法都会改进。混沌通过扩散吸引子来提高$λ_{\min}(M)$，但同时也会使其扩大并放大噪声；由于噪声以线性方式进入SINDy的回归瓶颈，而以超线性方式进入PySR的判别通道，同一转变可能将两种方法推向相反方向，因此更深的混沌并非总是更好。该框架中的无参数机制评分无需重新拟合即可迁移到留出的Lorenz-96系统，证实了其机制而非曲线拟合；从方程中读取的标准预测了何时添加混沌不会改善条件。我们还引入了Soft F1，一种系数加权的结构度量，可解决二元成功和预测评分无法察觉的性能差异。那么发现的首要问题不是哪种算法，而是吸引子允许什么。

## Abstract
Symbolic discovery of governing equations from data is limited not only by algorithm design and data volume, but by the geometry of the attractor: what the long-run dynamics allow to be recovered. Using a within-system design on Lorenz-84, where one forcing parameter drives fixed-point, limit-cycle, and chaotic regimes while the governing equations and library stay fixed, we show that a single number, $λ_{\min}(M)$, the smallest eigenvalue of the invariant-measure moment matrix, sets the identifiability ceiling for both sparse regression (SINDy) and evolutionary symbolic regression (PySR). Derived from the Birkhoff ergodic theorem and obtained from a short reference trajectory before any run, $λ_{\min}(M)$ measures how fully the attractor covers function space: where it vanishes, recovery is impossible for any algorithm, sparse or combinatorial alike; as it grows, both algorithms improve. Chaos raises $λ_{\min}(M)$ by spreading the attractor, but also enlarges it and amplifies noise; because noise enters SINDy's regression bottleneck linearly and PySR's discrimination channel superlinearly, the same transition can push the two methods in opposite directions, so deeper chaos is not uniformly better. Parameter-free mechanistic scores from this framework transfer without refitting to a held-out Lorenz-96 system, confirming mechanism rather than curve-fitting; a criterion read from the equations predicts when added chaos will not improve conditioning. We also introduce Soft F1, a coefficient-weighted structural metric that resolves performance differences invisible to binary-success and predictive scores. The first question of discovery is then not which algorithm, but what the attractor permits.

## 论文提出的方法论

### 核心思想
- 利用 **Birkhoff 遍历定理**：长时间轨迹的经验矩矩阵 $(1/N)\Theta^\top\Theta$ 收敛到吸引子不变测度下的**矩矩阵** $M = \int \Phi(x)\Phi(x)^\top d\mu(x)$。
- $M$ 是吸引子在函数空间中的"指纹"：它记录了字典项在长期动力学下的相关结构。其最小特征值 $\lambda_{\min}(M)$ 衡量吸引子对函数空间的覆盖完整度：
  - $\lambda_{\min}(M)=0$：信息不足，**任何算法**（无论稀疏或组合）都无法恢复；
  - $\lambda_{\min}(M)>0$ 但很小：恢复原则上可行，但取决于噪声和正则化容忍度；
  - $\lambda_{\min}(M)$ 增大：两类算法均受益。

### 关键技术细节
- **系统内设计（within-system design）**：在 Lorenz-84 中，单一强迫参数 $F$ 驱动系统经历不动点、极限环、混沌三种动力学状态，而控制方程、字典/算子集、评估协议完全不变，从而隔离"动力学状态"为唯一变量。
- **Soft F1 指标**：论文提出系数加权结构相似度指标，对每个匹配项按系数保真度加权 $w_j = \exp(-3\delta_j)$，其中 $\delta_j = |c_j-\hat{c}_j|/(|c_j|+|\hat{c}_j|)$。该指标能区分"结构对但系数偏差大"与"结构系数都对"的情况，优于二元结构 F1 和预测性指标（RMSE、R²）。
- **SINDy 机制模型**：基于 STLSQ 的误差-in-变量结构，构造两个威胁比：
  - 假阴性通道：$T_{FN} = \lambda / (w_{\min}\|\xi_{gt}\|)$，衡量最小真实系数是否会被岭回归收缩到阈值以下；
  - 假阳性通道：$T_{FP} = \kappa_{eff}\cdot\rho_{EIV}\cdot\sigma_\varepsilon/\lambda$，衡量噪声能否把虚假系数抬过阈值；
  - 综合评分 $F_{SINDy} = \max(T_{FN}, T_{FP})$（逻辑或：任一通道失效即失败）。
- **PySR 机制模型**：两个独立瓶颈：
  - **条件瓶颈**：$\sigma_{\min,partial}$——真实项被错误项组合所能解释后遗留的信号量（矩矩阵 Schur 补的最小奇异值）；
  - **信噪比判别瓶颈**：$Q_{noise}$——每个真实项未被最佳错误项解释的部分与噪声底的比值，经 leave-one-out 交叉验证；
  - 综合评分 $F_{PySR} = \sqrt{\sigma_{\min,partial}^{1/4} \cdot Q_{noise}}$。
- **无参数迁移**：所有指标不含拟合到发现结果的常数，直接从训练轨迹、算法配置、真实方程中计算。
- **噪声通道的非对称性**：噪声对 SINDy 线性进入（$T_{FP} \sim \kappa_{eff}\cdot\eta\cdot\sigma_x$），对 PySR 超线性进入（$Q_{noise}\propto(\eta\sigma_x)^{-n_{nc}}$，$n_{nc}=3$），这解释了为何同一转变（加深混沌）可让两种方法走向相反方向。
- **矩平衡理论**（Propositions S5.1–S5.4）：从方程结构判断"加深混沌是否改善条件数"——阻尼主导且被其他变量驱动的孤立坐标（如 L84 的 $x_0$）可能使方差停滞甚至下降，从而限制 $\lambda_{\min}(M)$；坐标置换对称性（如 L96）可排除该通道。

## 实验设计

### 数据集 / 场景
- **Lorenz-84（L84）**：受控系统，三维多项式 ODE。参数 $F$ 提供 8 个动力学状态：
  - R0：不动点（$\lambda_1 < -0.01$）；
  - R1–R2：两个极限环子状态（按吸引子振幅区分，而非 Lyapunov 指数）；
  - R3–R7：五个混沌子状态（按最大 Lyapunov 指数 $\lambda_1$ 分箱，覆盖从混沌 onset 到充分发展混沌）。
- **Lorenz-96（L96）**：零参数留出验证系统，五维环形方程，同样自带从不动点到混沌的完整分岔序列。所有机制指标从 L84 构建后**不修改直接应用于 L96**。
- **Jerk 系统**（补充材料）：非多项式 ODE 族（含非多项式真实项），用于验证框架不是多项式字典的伪影。

### 三个实验条件
1. **数据匮乏（starvation）**：无噪声、精确导数，训练集大小 $N \in [20, 10000]$（17 个 log 间距值）。
2. **噪声敏感性**：$N=5000$ 固定，高斯测量噪声 7 个信噪比水平 $\eta \in \{0, 0.01, 0.02, 0.05, 0.10, 0.15, 0.20\}$，导数估计用有限差分（FD）和 Savitzky–Golay 平滑（SG）两种方式。
3. **先验质量（prior quality）**：$N=5000$、无噪声，三种结构先验——null（字典中无真实项）、overcomplete（真实项+干扰项）、oracle（仅真实项）。

### 对比方法
- **SINDy**（PySINDy 实现，STLSQ 优化器）：固定稀疏阈值 $\lambda=0.05$、岭正则 $\alpha=0.05$。
- **PySR**：50 代进化、40 个并行岛，算子集 $\{+,-,\times\}$，最大复杂度 20 节点。
- 每个实验单元：SINDy 5 条独立轨迹槽；PySR 5 槽 × 5 次随机初始化 = 25 次运行。

### Benchmark 意义
- 所有基准均在**同一系统、同一方程、同一字典/算子配置**下进行，仅改变动力学状态——这是与以往跨系统 benchmark（如 Kaptanoglu et al. 2023；Gilpin 2021）的关键区别，后者因不同系统间方程复杂度混叠而无法识别状态信号。

## 论文的主要结论与发现

1. **动力学状态排序稳健**：恢复难度呈"不动点最难 < 极限环中间 < 混沌最容易"的排序，该排序在两种算法、三个实验条件下大体重现（数据极端和强噪声下存在系统性的反转）。
2. **单一标量 $\lambda_{\min}(M)$ 作为可辨识性上限**：该值从短参考轨迹即可计算，无需知道真实方程；为零时任何算法都不可能恢复（不动点处设计矩阵秩塌缩为 1，spark 崩溃到 2，Fisher 信息奇异），为正但小时决定噪声和正则化的容忍上限。
3. **两种算法的噪声通道不对称**：噪声对 SINDy 线性、对 PySR 超线性（3 次幂），导致同一动力学转变可让两方法反向移动；更深的混沌不一定更好，因为吸引子扩大同时带来覆盖增益和噪声代价。
4. **机制评分跨系统迁移**：$F_{SINDy}$ 和 $F_{PySR}$ 从 L84 构建后不修改即可在 L96 上保持强相关（Spearman 平均 0.81–0.87），证实捕获的是机制而非曲线拟合。
5. **方程结构可预测"混沌无益"的场景**：阻尼主导、孤立坐标（无交换对称性）的系统，其方差可能随混沌加深而停滞，从而限制 $\lambda_{\min}(M)$；坐标交换对称性（如 L96）则保证同步改善。
6. **Soft F1 指标揭示隐藏差异**：二元成功率和预测指标（RMSE、R²）无法区分的性能差异，Soft F1 可以区分；例如 null 先验下 R² 可达 0.64–0.80 但 Soft F1 仅 0.05–0.09，说明结构错误项可获得良好预测拟合。

## 不足与局限

- **论文明确承认的局限**：
  - 假设全状态可观测，未处理部分观测场景（提到延迟嵌入作为未来方向）；
  - $F_{SINDy}$ 需要知道哪些库项是真实的，因此是"事后诊断"而非"事前筛查"；
  - PySR 的两通道模型假设条件与判别瓶颈独立，未在相关噪声下验证；
  - 混沌内分析仅 5 个混沌状态/系统，不足以确定斜率，只能作为风险标记。
- **实验覆盖不足**：
  - 仅测试了低维 ODE（3–5 维），未涉及 PDE、随机微分方程、高维系统；
  - 未测试神经网络类发现算法（neural ODE、operator learning 等）——论文仅作为未来方向提及；
  - 噪声实验上限 20%，极端噪声下的行为未探索；
  - PySR 在 L84 噪声实验中的偏相关较弱（partial $|\rho|=0.46$），说明纯条件通道（$\sigma_{\min,partial}$）单独作用时预测力有限——论文承认此点，但读者需注意表 1 中 L84 PySR 的 SNR 列 0.81 主要来自判别通道。
- **偏差风险**：
  - 机制评分中 PySR 部分的外层幂次（1/4）和组合规则（几何平均）是在 L84 上经验选择的（虽然敏感性网格显示结论鲁棒，但严格说并非完全无参）；
  - 论文的 Spearman 相关描述性报告，未做多重比较校正（统计推断力度有限）；
  - 混沌状态的选择按 $\lambda_1$ 分箱，L84 中 $F$ 值在混沌区域内非单调，可能引入选择偏差（但论文给出了 $\lambda_1$ 与 $F$ 的非单调性说明）。
- **应用限制**：
  - 实际应用中 $\lambda_{\min}(M)$ 需要从轨迹估计，收敛速率（Proposition S3）依赖混合假设，对 L84/L96 未独立验证（论文已诚实标注）；
  - 预测试验的实用建议（"最大化 $\sigma_{\min}$ 同时控制 $\eta\sigma_x$"）需要可调的控制参数，对无法操控的系统仅能事后诊断。

## 结束语
本文通过系统内设计 + 遍历理论 + 算法机制建模，将系统发现的可辨识性上限归结为吸引子不变测度矩矩阵的最小特征值 $\lambda_{\min}(M)$，为符号发现领域提供了一个可预先计算的"可行性诊断"框架，并将研究的第一问题从"选什么算法"转向"吸引子允许什么"。
