## 摘要
物理信息神经网络（PINN）已成为求解偏微分方程（PDE）的强大范式，但其性能严重依赖于对神经表示、损失公式和优化动态的手动试错式工程设计。虽然大型语言模型（LLM）为自动化设计提供了有前景的途径，但在严格科学计算约束下，无约束的代码生成往往会产生数学上无效或数值上不稳定的解决方案。为弥合这一差距，我们提出了**EvoPINN**，一个智能体化框架，将PINN开发从劳动密集型的手动设计重塑为一个严谨的、基于执行的算法发现问题。EvoPINN通过将神经表示与训练程序解耦来导航模块化搜索空间，利用LLM智能体迭代地提出基于记忆条件的程序化修改。为确保科学有效性，所有候选方案都经过严格的结构验证和预算匹配的PDE评估。跨多种PDE场景（振荡型、椭圆型、耗散型和非线性输运型）的大量实验表明，EvoPINN发现了PDE特化的学习算法，与基线相比显著降低了相对$L_{2}$误差。关键在于，EvoPINN自主发明了SLRC-PINN，一种新颖的架构，其性能优势在严格的参数匹配比较下依然保持，确立了基于执行的智能体在发现真正新科学计算机制方面的可行性。

## Abstract
Physics-informed neural networks (PINNs) have emerged as a powerful paradigm for solving partial differential equations (PDEs), yet their performance heavily relies on the manual, trial-and-error engineering of neural representations, loss formulations, and optimization dynamics. While Large Language Models (LLMs) offer a promising avenue for automated design, unconstrained code generation often yields mathematically invalid or numerically unstable solutions under strict scientific computing constraints. To bridge this gap, we propose \textbf{EvoPINN}, an agentic framework that reformulates PINN development from labor-intensive manual design into a rigorous, execution-grounded algorithm discovery problem. EvoPINN navigates a modular search space by decoupling neural representations from training programs, utilizing an LLM agent to iteratively propose memory-conditioned programmatic modifications. To ensure scientific validity, all candidates undergo strict structural verification and budget-matched PDE evaluation. Extensive experiments across diverse PDE regimes (oscillatory, elliptic, dissipative, and nonlinear transport) demonstrate that EvoPINN discovers PDE-specialized learning algorithms that significantly reduce relative $L_{2}$ error compared to baselines. Crucially, EvoPINN autonomously invented SLRC-PINN, a novel architecture whose performance gains persist under rigorous parameter-matched comparisons, establishing the viability of execution-grounded agents for discovering genuinely new scientific computing mechanisms.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 总体框架

- PINN 算法被定义为一个二元组：
  \[
  A = (M, T) \in \mathcal{A} = \mathcal{M} \times \mathcal{T}
  \]
  其中 \(M\) 为神经表示（模型架构），\(T\) 为训练程序（优化器、损失、采样策略等）。
- EvoPINN 以种子 PINN 为起点，通过 LLM 引导的进化循环，在 \(G\) 代中迭代优化算法。每代生成 \(K\) 个程序化修改候选，在一个共享的训练预算 \(B\) 和随机种子 \(\xi\) 下执行训练，并用相对 \(L_2\) 误差作为搜索得分 \(S_{\text{search}}(A)\)。

### 2.2 三大核心机制

1. **模块化解耦与自适应调度（Module-Wise Evolution & Adaptive Scheduling）**
   - 每代只修改一个模块（\(M\) 或 \(T\)），另一个保持不变，以解决联合空间中性能提升的信用分配问题。
   - 采用 UCB 风格调度器动态决定下一轮进化哪个模块：
     \[
     c_g = \arg\max_{c \in \{M,T\}} \left[ \bar{r}_g(c) + \beta \sqrt{\frac{\log(N_g+1)}{N_{g,c}}} \right]
     \]
     其中 \(\bar{r}_g(c)\) 为模块 \(c\) 的近期平均奖励，\(\beta\) 控制探索与利用的权衡。
2. **诊断引导的程序生成（Diagnosis-Guided Program Generation）**
   - **训练诊断摘要** \(D_g\)：从训练轨迹中提取收敛进度、后期稳定性、物理损失与求解误差关系等五个诊断线索，为 LLM 提供可操作的修改指引。
   - **进化记忆**：记录先前成功的架构动机、失败模式、近期修改历史，避免重复探索。
   - **多样化搜索焦点**：为同一批次的 \(K\) 个 LLM 调用注入不同的探索方向（如特征构造、架构组织、优化动态、配点策略等），防止模式崩溃，促进批次多样性。
3. **程序验证与算法更新（Program Verification & Algorithm Update）**
   - **结构验证**：通过标准 AST 和归一化 AST 双重比较，过滤掉纯格式修改、标识符重命名和常数级改动——即排除纯超参数微调，保证只保留结构性新颖的机制。
   - **可执行测试与修复**：候选程序先在小规模 PINN 实例上测试接口兼容性、数值稳定性和自动可微性；失败程序可通过执行反馈进行有限次自修复。
   - **预算匹配评估**：所有候选在共享的训练步数、初始配点数、优化器家族等资源约束下评估，防止候选通过增加计算量来“作弊”取胜。
   - **严格改进更新**：只有候选程序在结构上新颖且降低了搜索集上的相对 \(L_2\) 误差时，才被接受为新的活跃算法。

## 6. 论文的主要结论与发现

1. **EvoPINN 发现的冻结算法在全部 4 个 PDE 基准上一致优于种子 PINN**，并在 Poisson2D、Burgers1D 和 Wave1D 上超过了最强的专家设计基线；在 Heat2D 上与专家基线基本持平。
2. **相较于其他自动化搜索范式（LLM Best-of-56、DPSTE、PINNsAgent），EvoPINN 在 Burgers1D 和 Wave1D 上达到最低误差**，证明了执行反馈 + 模块化解耦搜索的有效性。
3. **自主发明 SLRC-PINN**：一种自定位残差校正架构，结合全局持久锚定、自组织校正支持和函数保持的渐进扩展三大设计原则。该架构在参数匹配对照下比同容量全局 MLP 降低 55.1% 的均方误差，且优于 APINN、FBPINN、HyResPINNs 等域分解方法。
4. **自主发明 TCROP 训练策略**：一种基于遥测条件的重采样与优化器策略，通过动态分配 Adam（17,200 步）和 L-BFGS（2,800 步）并结合全局配点周期性刷新，在 Poisson2D 上比传统的 10k/10k 固定分配降低 27.5% 的几何平均误差。
5. **消融实验表明**：训练诊断摘要对 LLM 定向突变至关重要（尤其对 Wave1D）；模块化独立进化比联合突变更稳定；表示与训练程序的联合协同设计缺一不可。
6. **参数迁移测试表明**：冻结的 EvoPINN 算法具有零样本迁移能力，能适配相邻 PDE 参数，特别是 Heat2D 上，专家基线在频率偏移时性能大幅下降，而 EvoPINN 保持稳定精度——说明其发现的机制具有频率鲁棒性而非参数过拟合。

## 7. 优点

- **范式创新性**：首次将 PINN 自动化设计从“配置选择”提升到“开放式算法发现”的层面，突破了既有模板的限制。
- **模块化信用分配**：一次只改一个模块，使性能变化的归因清晰，降低调优难度。
- **诊断引导的可操作反馈**：将稀疏的标量误差转化为包含收敛趋势、稳定性等信息的诊断摘要，大幅提升 LLM 修改建议的针对性。
- **严谨的验证流水线**：AST 结构验证、可执行测试修复、预算匹配评估三层保障，确保候选的数学有效性和评估公平性；结构验证过滤纯超参数修改，使发现产物具有机制层面的新颖性。
- **科学发现的实证严谨性**：SLRC-PINN 通过参数匹配对照、多随机种子重训练和搜索/报告集分离协议验证，防止了单纯容量或调参导致的假阳性结果。
- **泛化能力验证充分**：参数迁移测试独立于主实验，证明了发现的机制具有物理参数层面的可移植性。

## 8. 不足与局限

- **依赖 LLM 的生成能力**：发现机制的创造力和质量受限于底层 LLM（gpt-5.4-mini）的代码合成与科学推理能力；更强的模型可能产生更优机制，但也带来更高的 API 成本和不可控性。
- **搜索计算成本较高**：每代候选都需要完整预算的 PINN 训练，整个搜索累计需要数十 GPU 小时；论文承认这一限制，并指出未来需引入代理目标或替代评估来加速候选筛选。
- **外部有效性有限**：实验仅在 4 个 PDE 场景上验证，虽然覆盖多种类型，但尚未涉及时变复杂几何、耦合多物理场、高维 PDE 等问题；对真实工业级科学计算场景的适用性尚未证明。
- **未充分个体化隔离机制贡献**：TCROP 的结果虽然验证了整体联合策略的有效性，但论文明确声明未对预算分配与重采样策略分别做因果归因；SLRC-PINN 的拓扑原则（全局锚定、门控支持、零初始化）也未做逐项消融。
- **“新颖性”判定的程序性限制**：结构验证基于 AST 差异，只能检测源码层面的修改，无法证明语义层面的真正创新；一些形式上不同但本质上等价的机制可能被误判为新发现。
- **训练程序搜索存在波动风险**：消融实验中 w/o modular 在 Wave1D 上仅完成 12/56 个候选评估，说明联合突变在部分场景下执行稳定性较差，可能带来选择性偏差。
- **搜索结果的可解释性**：尽管 SLRC-PINN 有清晰的数学表述和机制解释，但自动发现过程本身缺乏对 LLM 推理路径的可视化和归因分析，黑箱程度仍然较高。
