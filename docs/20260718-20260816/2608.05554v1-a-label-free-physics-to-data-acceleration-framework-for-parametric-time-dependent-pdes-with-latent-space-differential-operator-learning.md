## 摘要
含时参数偏微分方程的高效求解是计算科学与工程的核心问题。现有的基于深度学习的加速方法覆盖了从物理到数据的谱系，从具有强物理一致性但计算成本高的物理信息求解器，到推理高效但对高保真数据集依赖性强的数据驱动代理模型。这些方法在很大程度上是孤立发展的，通常仅通过显式解场标签相互关联。我们提出了PHD-SF，一个用于加速含时参数偏微分方程的紧凑物理到数据谱系框架。通过将SD-TPD分离策略与微分算子学习相结合，PHD-SF允许可复用的模型信息，包括空间特征、潜在动力学特征和空间微分算子，在统一基于DON的架构中通过三种运行模式（PIDON、HIDON和DIDON）生成、继承和丰富。该设计无需预先计算的全场解标签或模式间的显式标签转移即可实现无标签谱系建模。PHD-SF进一步建立了一条分离求解、类超缩减丰富和直接推理的加速路径，降低了对大规模高保真数据生成及其离线成本的依赖。在四个基准含时偏微分方程上的结果表明，仅需在初始物理信息阶段使用一个或两个代表性参数案例，即可实现准确的跨参数求解和直接推理。总端到端成本低于训练单个参数案例的传统PINN所需成本，同时支持可复用的跨参数推理。因此，PHD-SF为多查询参数偏微分方程提供了一条高效求解路径。

## Abstract
Efficient solution of time-dependent parametric partial differential equations (PDEs) is central to computational science and engineering. Existing deep-learning-based accelerators span a physics-to-data spectrum, from physics-informed solvers with strong physical consistency but high computational cost to data-driven surrogates with efficient inference but strong dependence on high-fidelity datasets. These methods have largely evolved in isolation and are often connected only through explicit solution-field labels. We propose PHD-SF, a compact physics-to-data spectrum framework for accelerating time-dependent parametric PDEs. By combining an SD-TPD separation strategy with differential-operator learning, PHD-SF allows reusable model information, including spatial features, latent dynamical features, and spatial differential operators, to be generated, inherited, and enriched across three operating modes, PIDON, HIDON, and DIDON, within a unified DON-based architecture. This design enables label-free spectrum modeling without precomputed full-field solution labels or explicit label transfer among modes. PHD-SF further establishes a separated-solving, hyper-reduction-like enrichment, and direct-inference acceleration path, reducing the dependence on large-scale high-fidelity data generation and its offline cost. Results on four benchmark time-dependent PDEs show accurate cross-parameter solution and direct inference using only one or two representative parameter cases in the initial physics-informed stage. The total end-to-end cost is lower than that required to train a conventional PINN for a single parameter case, while supporting reusable cross-parameter inference. PHD-SF therefore provides an efficient solution path for many-query parametric PDEs.

  - 物理约束强的求解器（如PINN）：物理一致性高，但计算成本高、跨参数泛化能力弱；
  - 数据驱动的代理模型（如DeepONet、FNO）：推理高效，但严重依赖大规模高保真解标签数据集。
- **关键洞察**：谱系上不同模型之间的关联不应仅仅被理解为显式解标签的转移。上游求解过程中形成的可复用模型信息（空间特征、潜在动力学特征、微分信息等）可以成为更深层的连接载体。
- **核心问题**：能否在统一架构中实现可复用模型信息的生成、继承和丰富，从而以无标签方式贯通“物理约束求解 → 混合建模 → 快速直接推理”的完整路径？

## 2. 论文提出的方法论

### 2.1 核心思想

- **PHD-SF框架**：提出一个紧凑的物理到数据谱系框架，统一基于DON（微分算子网络）架构，包含三种运行模式：**PIDON**（物理信息微分算子网络）、**HIDON**（物理-数据混合信息DON）、**DIDON**（数据驱动DON）。
- **核心创新**：跨阶段可复用模型信息的生成—继承—丰富机制，以**无标签**方式实现谱系建模，既不需要预计算的高保真解快照，也不需要模式间显式解标签转移。

### 2.2 关键技术一：SD–TPD分离策略

- 将近似解显式分解为空间基函数（BFs）和时间-参数基坐标函数（BCFs）的乘积和：
  \[
  \hat{u}(x,z) = \sum_{i=1}^{n_b} a_i(z)\varphi_i(x) = \Phi(x)^T A(z)
  \]
- SpatialNet输出BFs编码空间特征，TPNet输出BCFs编码潜在时间-参数动力学特征。
- 证明该分离函数类在连续解空间中具有一致稠密性（结合Stone-Weierstrass定理和神经网络泛逼近定理）。
- 计算复杂度从全网格乘积\(N_x N_z\)降为加法\(N_x + N_z\)，实现线性可扩展。

### 2.3 关键技术二：微分算子学习策略

- 将近似解的微分运算转移到分离的潜在因子上：时间微分作用于BCFs，空间微分算子作用于BFs。
- 通过自动微分（AD）对BFs施加已知控制方程的空间微分算子，显式获得**空间微分算子信息（SDOs）**。
- 与常规物理信息求解器的区别：不是直接对近似解施加AD，而是对BFs施加AD以获得可复用的微分算子（对比见图2）。

### 2.4 三种运行模式

- **PIDON（物理信息求解与空间特征学习）**：
  - 同时优化SpatialNet和TPNet，求解一到两个代表性参数案例；
  - 生成可复用的BFs、SDOs和初始BCFs；
  - 损失函数包含PDE残差、边界条件、初始条件和正交正则化四项。
- **HIDON（潜在动力学特征丰富）**：
  - 继承PIDON学到的BFs和SDOs，冻结SpatialNet，仅更新TPNet；
  - 将原始PDE约化为低维潜在ODE系统，仅在稀疏空间采样点上施加方程约束（类超缩减效果）；
  - 在大规模参数案例上丰富BCFs中编码的潜在动力学特征。
- **DIDON（直接推理）**：
  - 直接继承训练好的SpatialNet（来自PIDON）和丰富后的TPNet（来自HIDON）；
  - 不再施加任何方程约束，以可忽略的在线成本进行跨参数直接推理。

### 2.5 算法流程（PHD-SF流水线）

1. PIDON阶段：在SD集上计算BFs及SDOs（AD）、在TPD集上计算BCFs及时间导数（AD）→ 组装残差 → Adam优化更新两个子网络；
2. 预计算阶段：在稀疏空间集上计算并存储稀疏BFs和SDOs；
3. HIDON阶段：仅更新TPNet，在稀疏空间点上施加约化ODE约束，在大量参数案例上优化BCFs；
4. DIDON阶段：已冻结的SpatialNet与TPNet直接组合进行推理。

## 6. 论文的主要结论与发现

1. **无标签谱系建模可行**：PHD-SF仅需一个或两个代表性参数案例的物理信息求解，即可获得准确的跨参数直接推理能力，无需任何高保真解标签。
2. **端到端效率优势显著**：总计算成本低于训练单个PINN案例，同时提供PINN不具备的跨参数推理能力。在典型基准上，PIDON相对PINN实现约两到三个数量级的墙钟加速。
3. **类超缩减效果**：HIDON通过稀疏空间采样（典型\(n_s/n_b \approx 2\sim10\)），将高维PDE约化为低维潜在ODE系统，实现与空间分辨率解耦的成本。
4. **PIDON学到的基函数优于POD模态**：
   - 在目标参数域内残差能量比POD低3–4个数量级，潜空间覆盖更好；
   - 空间可微且天然关联SDOs；无截断误差；可热启动迁移。
5. **稀疏采样比例存在平台效应**：误差随\(n_s/n_b\)增大而下降，约10倍后趋于饱和；非均匀采样在小样本时更优。
6. **PHD-SF提供了一条“分离求解—类超缩减丰富—直接推理”的加速路径**，填补了物理约束强度与数据依赖之间的谱系空白。

## 7. 优点

- **框架层面的整合性**：首次将物理信息求解、混合丰富、直接推理组织为统一架构的三种运行模式，通过参数冻结和阶段切换实现信息继承，而非模型间的标签转移。
- **微分算子学习策略新颖**：将微分从近似解转移到BFs，使微分信息本身成为可复用资源，为后续阶段提供空间微分算子的直接供给。
- **计算复杂度的双重降低**：SD-TPD分离将网络评估次数从乘积降为加法；HIDON的稀疏空间采样使计算成本与空间分辨率解耦，具备空间尺度无关性。
- **理论支撑充分**：包含了可分离函数类的稠密性证明（命题S1）、HIDON闭包性分析（维度计数与局部可辨识性条件）、RE定义等，理论深度较好。
- **实验验证全面**：四个差异显著的基准问题，多种消融分析，效率与精度双维度报告，对比公平性设计得当。
- **基函数可解释性与可迁移性**：BFs具有明确的物理含义（空间特征），且与POD相比在潜空间覆盖上显著更优。

## 8. 不足与局限

- **稀疏采样策略简单**：HIDON使用均匀采样作为基线，论文承认非均匀采样在小样本时更优，但未提出系统的最优点选择算法（仅做了初步的高斯偏置验证）。缺乏如DEIM贪心选择、自适应采样或误差指示器引导的采样方法。
