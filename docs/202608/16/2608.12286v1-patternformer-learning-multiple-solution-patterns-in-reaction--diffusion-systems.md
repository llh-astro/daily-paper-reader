## 摘要
许多物理学、化学和生物学中的非线性模型在相同参数下表现出多个解，而捕获整个解集对于理解模式形成系统至关重要。然而，现有的学习代理从根本上说是单值的：神经算子将每个参数映射到单一输出，物理信息神经网络则收敛到一个分支。我们开发了PatternFormer（PF），一种基于大语言模型的框架，用于学习非线性偏微分方程的多个解。通过将无序的共存解转换为规范序列，PF在单次自回归传递中生成结构化解集，对于有限族自动终止，对于无界族则强制执行物理残差约束。在非线性椭圆问题上，它在一个推理步骤中恢复所有解分支；在Gray-Scott问题上，它生成共存的图灵模式，包括参考数据中未出现且超出训练范围的物理有效状态。PF还可以在多稳态系统间进行顺序微调，朝着解景观的通用基础模型发展。

## Abstract
Many nonlinear models across physics, chemistry, and biology exhibit multiple solutions for the same parameters, and capturing this entire solution set is essential for understanding pattern-forming systems. Yet existing learned surrogates are fundamentally single-valued: neural operators map each parameter to a single output, and physics-informed neural networks converge to one branch. We develop \textbf{PatternFormer} (PF), a large language model-based framework for learning the multiple solutions of nonlinear partial differential equations. By transforming unordered coexisting solutions into canonical sequences, PF produces structured solution sets in a single autoregressive pass, terminating automatically for finite families and enforcing physical residual constraints for unbounded ones. On nonlinear elliptic problems it recovers all solution branches in one inference step; on Gray--Scott it generates coexisting Turing patterns, including physically valid states absent from the reference data and beyond training. PF can also be sequentially fine-tuned across multistable systems, toward general foundation models for solution landscapes.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：许多物理、化学和生物系统中的非线性模型（尤其是反应-扩散系统）在相同参数下具有**多重稳态解**（multistability）。例如 Gray–Scott 模型中同一参数可支持多个共存的 Turing 模式。科学目标常常不是求单一解，而是刻画**整个解集**（solution landscape）。
- **现有方法的根本局限**：
  - **神经算子**（如 DeepONet、FNO）本质上是单值映射 `p → u(p)`，无法表达“一参数对应多解”的关系；
  - **物理信息神经网络（PINNs）** 在多稳态系统中通常只会收敛到单一条分支；
  - 传统数值方法（homotopy continuation、deflation 等）虽能发现多解，但计算成本随解数量和参数维度急剧增长；
  - 生成式模型在 PDE 场景中输出的多是**不确定性或随机变异性**，而非不同的稳态解。
- **核心问题**：能否设计一个统一的框架，直接学习“参数到解集合”的**集值算子**（set-valued operator），在单次推理中恢复全部共存稳态？
- **整体含义**：论文提出 PatternFormer (PF)—— 一种基于预训练大语言模型（LLM）的框架，将多解生成问题转化为自回归序列生成问题，从而实现单次前向传递生成多个物理上有效、结构上不同的解。该工作代表了科学机器学习从“学习输入-输出函数”向“学习结构化科学景观”转变的尝试。

### 2. 方法论：核心思想、关键技术细节与算法流程

#### 2.1 核心思想
- 目标学习集值算子：
  \[
  G: p \mapsto S(p) = \{u_1, \dots, u_{K(p)}\}
  \]
  其中 \(S(p)\) 为参数 \(p\) 下全部共存稳态的集合。
- 关键转化：共存解本是无序集合，通过基于**解范数的规范序**（canonical ordering）将其转化为确定性的有序序列，从而适配自回归生成模型。

#### 2.2 模型架构（六大部分）
1. **冻结的卷积自编码器**：将解场 \(u\) 压缩为 256 维潜在向量 \(z = E(u)\)，并通过 \(u = D(z)\) 重建；
2. **可学习的结构嵌入**：块起始标记 \(v_s\)、解分隔符 \(v\)、终止标记 \(v_p\)（均为 3584 维，匹配 Qwen2.5-7B 的输入空间）；
3. **输入匹配层 \(g_{in}\)**：两层 MLP+GELU，将拼接的 \([z;p]\) 投影到 LLM 嵌入空间；
4. **冻结的 Qwen2.5-7B 变换器**：作为序列生成骨干，通过因果注意力处理连续嵌入；
5. **输出匹配层 \(g_{out}\)**：将隐状态映射回潜在维度；
6. **双预测头**：潜在回归头（生成解表示）+ 标记分类头（当解数量已知时用于自适应终止）。

#### 2.3 训练策略

- **序列构造**：对于参数 \(p\) 及其有序解 \(u^{(1)} \prec \cdots \prec u^{(K)}\)，构造连续序列块：
  \[
  B(p) = [v_s,\ g_{in}(0,p),\ v,\ \tilde{z}_1,\ v,\ \tilde{z}_2,\ \ldots,\ v,\ \tilde{z}_K,\ v_p]
  \]
- **三阶段训练**：
  1. 预训练自编码器（仅重建损失），然后冻结；
  2. **带上下文阶段**：在目标参数前注入若干上下文示例块 \(B(p_1),\dots,B(p_M)\) 作为 demo；
  3. **去上下文阶段**：移除上下文，使模型学会仅从参数直接生成。

- **两种生成模式**：
  - **Stop-token 设计**（适用于解数量理论上已知的椭圆问题）：训练模型在最后一个真实解后输出停止标记，损失函数为：
    \[
    L_{stop} = \sum_{k=1}^{K(p)} [\lambda_{mse}\|\hat{u}_k - u_k\|^2 + \lambda_{pde} ReLU(R(\hat{u}_k;p)-\epsilon)] + \lambda_{ce} L_{marker}
    \]
  - **Fixed-budget 设计**（适用于 Gray–Scott 等解数量未知/无界系统）：固定生成 K=24 个解槽位，前 \(K_t\) 个（头）用真实解进行 teacher-forcing，后 \(K_t+1 \sim K\) 个（尾）用模型自身预测自由运行，由物理残差损失驱动：
    \[
    L = \sum_{k=1}^{K}\{[\lambda_{mse}\|\hat{u}_k-u_k\|^2 + \lambda_{lat}\|\hat{z}_k-z_k\|^2]\mathbb{1}[k\le K_t] + \lambda_{pde} ReLU(R(\hat{u}_k;p)-\epsilon)\}
    \]

- **物理残差正则**：采用 **hinge 形式的残差惩罚** \(ReLU(R(\hat{u};p)-\epsilon)\)，避免损失将所有输出推向平凡解，同时保证生成状态满足控制方程。
- **多重度加权采样**：按参数解数量 \(K_t\) 增加其采样概率，避免高多重度参数被忽略。
- **推理**：一次自回归前向传递生成全部潜在表示，解码后作为经典 Newton 求解器的初值，快速收敛到机器精度。

### 6. 主要结论与发现

1. **单步完整解集恢复**：在非线性椭圆问题（Examples 1–3）上，PF 在单次前向传递中即可恢复全部共存解分支，直接生成的解中位相对 L2 误差约 \(2.3\times10^{-2}\)，经 3–4 次 Newton 迭代后可降至 \(2.9\times10^{-8}\)。
2. **泛化与迁移**：模型在训练网格（N=1024）上训练后可迁移到更细网格（N=2048、4096）；通过 warm-start 可在不同方程间迁移并降低验证损失。
3. **开放发现能力**：Gray–Scott 系统中，PF 能生成参考数据中不存在的、物理有效的图灵模式（在某参数下发现 63 个稳态，其中 61 个为新的）；噪声增强可将每参数平均发现解数从 2.90 提升到 8.39。
4. **外推能力**：直接外推在训练区域附近有效；结合 PF 初始化与 homotopy continuation，可将完整分支结构传输到远超训练范围（如 Example 1 外推到 p=100，约为最大训练参数的 5 倍以上）。
5. **预训练与 warm-start 的贡献**：预训练 LLM 权重比随机初始化更好（Gray–Scott 中每参数发现解数从 1.44→3.23）；跨方程 warm-start 进一步提升至 5.18。
6. **“生成 vs 精修”的角色分离**：模型负责发现解分支，数值精修只是提高精度（3–4 次 Newton 迭代），不是搜索的关键。

### 7. 优点

- **概念创新**：将多稳态 PDE 求解重构为“集值算子学习 + 序列生成”，突破了神经算子单值映射的根本限制，为科学机器学习提供了新范式。
- **利用 LLM 的生成能力**：创新性地将预训练 LLM 用作连续科学表示的序列生成骨干，避开离散 tokenization，展示了 LLM 在科学计算中的迁移潜力。
- **物理约束的巧妙设计**：hinge 残差损失既能约束生成状态满足 PDE，又避免将所有输出拉向平凡解，是保证“有效发现”而非“数值伪影”的关键。
- **系统化的训练策略**：带上下文→去上下文的渐进训练 + 解数量加权采样 + scheduled sampling，处理了训练-推理不一致问题和高多重度样本稀缺问题。
- **严格验证流程**：所有生成解均通过 Newton 精修至残差 \(<10^{-9}\) 并去重，保证了结果的可信度。
- **计算效率显著**：相比传统多重解求解器，在细网格上快 4–57 倍（视分辨率和参数而定）。
- **跨系统迁移路径清晰**：展示了从 1D 单参数 → 1D 双参数 → 2D 椭圆 → Gray–Scott 的顺序迁移路线，为通用解景观基础模型提供了可行路径。

### 8. 不足与局限

- **外推能力有限**：直接前馈生成在远离训练参数范围时退化明显，需借助 homotopy seeding 或逐步推进才能维持覆盖。
- **固定离散化**：模型在单一固定空间离散化上训练，虽可内插到更细网格，但尚未实现真正离散化无关（discretization-agnostic）的泛化。
- **计算资源不透明**：未报告 GPU 规格、训练时长、能耗等，影响可复现性和成本评估。
- **缺少同类方法的直接对比**：未与 HomPINNs、deflation-based 多解学习方法或其他多解生成模型（如 GINN）进行公平的 benchmark 对比。
- **开放发现的可控性不足**：Gray–Scott 中“哪些参数能发现新解”似乎不可预测，噪声增强虽增加发现数量但对每个参数的增量不均（均值从 2.9 到 8.4，但分布方差较大）。
- **对称性处理依赖人工**：D4 对称性归约是人工设计的，未来系统若具有更复杂对称群，该策略需扩展。

- **理论支撑不足**：对于“为什么 LLM 的自回归结构能有效生成解集合”缺乏严谨的数学论证，更多是经验性验证。
