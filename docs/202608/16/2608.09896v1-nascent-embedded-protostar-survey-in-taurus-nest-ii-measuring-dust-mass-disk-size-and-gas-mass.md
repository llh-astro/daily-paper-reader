## 摘要
包层嵌入的原恒星盘代表了原行星盘演化的最早阶段，但由于盘发射与包层纠缠在一起，其质量和大小的测量十分困难。我们利用ALMA 7波段（345 GHz；约0.3角秒）和VLA Ka波段（33 GHz；约0.2角秒）的连续谱观测，结合分子谱线数据，分析了金牛座中的26个原恒星盘系统，以约束盘气体质量。在345 GHz下，流量密度、尘埃质量和半径的中位数分别为71毫央斯基、5.5地球质量和28天文单位，68%的范围分别为54-107毫央斯基、3.9-9.4地球质量和25-39天文单位。在33 GHz下，相应的中位数分别为0.43毫央斯基、39地球质量和32天文单位，范围分别为0.41-0.80毫央斯基、34-52地球质量和29-33天文单位。金牛座I类盘比猎户座中的更暗且质量更小，与英仙座I类盘相当，但比英仙座0类盘更暗，且比蛇夫座中的更亮、质量更大。在金牛座内部，0类/I类盘在两个频率下都比II类盘更亮，尽管它们在345 GHz下推断的尘埃质量相当，在33 GHz下略高。对CO同位素分子发射的辐射转移建模得出气体质量的中位数为6.7×10^-4太阳质量。由此得到的CO推断气体-尘埃比分布范围很广，平均值为147±75，中位数为26，第16至第84百分位范围为8-147。该分布在低端与金牛座II类星族重叠，在高端则呈现类星际介质或更高的值，包括蛇夫座AGE-PRO 0类/I类星族。

## Abstract
Envelope-embedded protostellar disks represent the earliest stage of protoplanetary disk evolution, but their masses and sizes are difficult to measure because disk emission is entangled with the envelope. We analyze 26 protostellar disk systems in Taurus using ALMA Band 7 (345 GHz; ~0.3'') and VLA Ka-band (33 GHz; ~0.2'') continuum observations, together with molecular-line data to constrain disk gas masses. At 345 GHz, the median flux density, dust mass, and radius are 71 mJy, 5.5 M_Mearth, and 28 AU, with 68% ranges of 54-107 mJy, 3.9-9.4 M_Mearth, and 25-39 AU. At 33 GHz, the corresponding medians are 0.43 mJy, 39 M_Mearth, and 32 AU, with ranges of 0.41-0.80 mJy, 34-52 M_Mearth, and 29-33 AU. Taurus Class I disks are fainter and less massive than those in Orion, comparable to Perseus Class I disks but fainter than Perseus Class 0 disks, and brighter and more massive than those in Ophiuchus. Within Taurus, Class 0/I disks are brighter than Class II disks at both frequencies, although their inferred dust masses are comparable at 345 GHz and slightly higher at 33 GHz. Radiative-transfer modeling of CO isotopologue emission yields a median gas mass of 6.7 x 10^-4 M_Msun. The resulting CO-inferred gas-to-dust ratios span a broad range, with a mean of 147 +/- 75, a median of 26, and a 16th-84th percentile range of 8-147. This distribution overlaps the Taurus Class II population at the low end and ISM-like or higher values, including the AGE-PRO Ophiuchus Class 0/I population, at the high end.

## 论文详细总结

### 1. 核心问题与整体含义（研究动机与背景）

- 原行星盘是行星诞生的场所，而包层嵌入的 Class 0/I 原恒星盘（年龄 <1 Myr）代表了原行星盘演化的最初阶段。理解这些最年轻盘的初始质量预算（尘埃与气体）和空间尺度，对于揭示行星形成的时间线、初始条件以及“从盘到行星系统”的物理路径至关重要。
- 然而，这类嵌入原恒星盘在观测上面临突出困难：盘发射与周围包层发射纠缠不清，需要足够高的角分辨率才能将两者分离；多数早期研究局限于单目标或小样本，缺乏对单一恒星形成区内完整星族的系统性普查。
- 已有的 Class II 盘（较年老盘）研究表明，观测到的尘埃质量系统性低于构建巨行星核心所需的固体质量，暗示固体物质可能已提前演化为大天体或从毫米波段“消失”。因此，直接测量最年轻盘的尘埃质量，是判断行星形成是否在极早期就已启动的关键。
- 过去的大样本巡天（如 VANDAM、ODISEA、MASSES、eDisk 等）虽然大幅扩展了样本量，但在分子谱线覆盖上不足以在整样本上追踪盘的 bulk 气体质量，或者偏向于亮源选择而非区域完整普查。
- **核心意义**：本文提出了首个针对单一恒星形成区（金牛座）内所有一致分类的 Class 0/I 系统的“尘埃 + 气体”统一普查（NEST II），为早期盘演化和行星形成初始条件提供了关键的观测约束。

### 2. 方法论：核心思想、关键技术细节与流程

**总体思路**：结合高频（ALMA 345 GHz）与低频（VLA 33 GHz）连续谱观测测量尘埃分量，结合 CO 同位素分子线（¹³CO 和 C¹⁸O J=3–2）观测并以开普勒掩模（Keplerian mask）隔离盘发射，再通过辐射转移模型网格反演推断气体质量。

**关键技术细节与流程**：

1. **连续谱尘埃质量测量（Hildebrand 1983 方法）**：
   - 用 CASA `imfit` 对连续谱图像做二维高斯拟合，提取积分流量、去卷积主轴/次轴、位置角，并推断盘倾角。
   - 尘埃质量采用标准光薄等温流量-质量关系：

     **M_dust = F_ν · d² / [κ_ν · B_ν(T_dust)]**

   - 尘埃不透明度采用 **κ_ν = 10(ν/1000 GHz)² cm²/g**（Beckwith & Sargent 1991），即 κ₃₄₅ = 3.45 cm²/g、κ₃₃ = 0.33 cm²/g。
   - 尘埃温度按光度标定：**T_dust = T₀(L_bol/1L_☉)^0.25**，T₀ = 43 K（Class 0/I 盘），Class II 盘则取 25 K。
   - 尘埃半径定义为去卷积主轴的 2σ 展度：**R_dust = (2/2.355)·θ_maj,decon·d**；未分辨源报告上限。

2. **CO 气体质量测量（辐射转移模型网格反演）**：
   - 使用 `keplerian_mask.py`（Teague 2020）构建 3D (x–y–v) 开普勒掩模，以隔离盘发射、排除包层污染。
   - 掩模参数包括盘倾角、位置角、恒星质量、系统速度、外半径（通常为 1.0–3.0×R_dust）和 z/r 垂直结构。
   - 恒星质量确定采用双重判据：① ¹³CO 通道延展法（S/N≥3σ 的边通道判据）；② C¹⁸O 的 χ²-like 残差最小化法。最终目视检查确认。
   - 用 pdspy（封装 RADMC-3D）构建包含原恒星 + 黏性演化盘 + Ulrich 内落包层的辐射转移模型网格，参数空间覆盖恒星质量（0.5–1.5 M_☉）、光度（0.1–25 L_☉）、盘尘埃质量、临界半径（10–200 AU）、面密度指数、翘曲指数、包层质量（10⁻⁵–10⁻³ M_☉）、倾角（0°–75°）等，共 29,160 对 ¹³CO/C¹⁸O 模型。
   - 对每个模型生成对应的开普勒掩模并应用于合成线立方体，得到模型线光度；将观测线光度与半径匹配（±50%）的模型子集比较，以 ¹³CO/C¹⁸O 光度比和 C¹⁸O 光度为双重约束，赋予各离散气体质量权重，取加权分布中位数及 16–84 百分位作为气体质量估计。

3. **统计分析**：
   - 采用 Kaplan–Meier 估计量构建 CDF，处理非探测源的“截尾数据”（上限）。
   - 采用 Peto–Peto 检验比较不同截尾分布的兼容性（p 值）。

### 6. 主要结论与发现

1. **金牛座 Class 0/I 盘的尘埃性质**：
   - 345 GHz：中位流量 71 mJy，中位尘埃质量 5.5 M⊕，中位半径 28 AU（范围 8–736 AU）。
   - 33 GHz：中位流量 0.43 mJy，中位尘埃质量 39 M⊕，中位半径 32 AU。
   - 两种频率推导的尘埃质量存在系统性差距（约 5.7 倍），可能反映不透明度频率依赖、光学厚效应或 33 GHz 自由-自由污染。

2. **跨区域对比**：
   - 猎户座 Class 0/I 盘在 345 和 33 GHz 均显著比金牛座更亮、质量更大（p < 0.05），与“猎户座含更多大质量原恒星 → 更重盘”的 IMF 预期一致。
   - 英仙座 Class 0 盘比金牛座 Class I 盘更亮更重；英仙座 Class I 与金牛座 Class I 相当。
   - 蛇夫座 Class I 盘在 345 GHz 显著更暗、质量更小、半径更小（中位半径仅 7 AU），可能是云/核尺度的初始条件差异所致。

3. **金牛座 Class 0/I vs Class II 盘**：
   - Class 0/I 盘在 345 和 33 GHz 都更亮（p = 0.006 和 0.0011），但 345 GHz 推断的尘埃质量分布与 Class II 相当（p = 0.60），33 GHz 略高（p = 0.06）。
   - 这与许多前人“Class 0/I 尘埃质量高于 Class II”的结论不同，反映出温度、不透明度、光学厚等假设的敏感性。

4. **气体质量与气体-尘埃比**：
   - 中位气体质量 M_gas,med = 6.7×10⁻⁴ M☉（16–84 百分位：1.1×10⁻⁴–1.3×10⁻² M☉）。
   - 气体-尘埃比：均值 147±75，中位数 26，16–84 百分位范围 8–147。
   - 分布低端与金牛座 Class II 盘（KM 中位数 9–14）重叠，高端（~100–1000）与蛇夫座 AGE-PRO Class 0/I 样本相当。
   - 提示早期盘中部分源已接近后期盘的 CO 消耗特征，部分源仍保留 ISM 类比例，演化并非单调。

### 7. 优点

- **区域完整普查**：首个对单一区域所有一致分类 Class 0/I 系统的尘埃+气体联合普查，规避了过往亮源选择的系统偏差。
- **多频互补**：ALMA 345 GHz 与 VLA 33 GHz 联合使用，高频追踪盘主体，低频对光学厚不敏感，能交叉验证质量估计。
- **频率匹配的跨区域比较**：各区域样本严格按频率分别比较、统一距离标定、统一质量换算方法，显著抑制了系统误差。
- **开普勒掩模技术**：相比简单的速度积分/像素选择，可有效削弱包层污染，更忠实提取盘的气体发射。
- **辐射转移网格反演**：使用 RADMC-3D 网格（含 Ulrich 包层、CO 冻结等物理）而非简单光薄/LTE 假设，气体质量估计更物理自洽，并给出了非对称不确定度。
- **敏感性测试**：明确评估了 CO 丰度（±1 dex → 气体质量 ±0.11–10 倍）和冻结温度（±5 K → 约 25–50%）的影响，透明化系统不确定度来源。
- **统计严谨**：Kaplan–Meier 估计与 Peto–Peto 检验正确处理了截尾数据（非探测上限），结论可靠。

### 8. 不足与局限

- **系统不确定性未完全解决**：
  - 尘埃不透明度采用固定幂律，未考虑不同来源/区域间尘埃性质差异（可能达数量级偏差）。
  - 光学厚效应：345 GHz 部分源可能光厚，导致尘埃质量被低估（τ~1 和 2 分别低估约 1.6 和 2.3 倍）；未做逐源修正。
  - 33 GHz 自由-自由辐射未逐源分离（估计中位贡献 10–15%，个别源可达 ~100%），可能导致 VLA 尘埃质量被高估。
- **气体质量依赖模型假设**：
  - CO 丰度（x_CO = 10⁻⁴）、同位素比、冻结温度（20 K）均为固定值；未涉及同位素选择性光解离、CO 化学转化等更复杂化学过程。
  - 恒星质量来自开普勒掩模的近似估计（主观目视成分），真正的恒星质量需更自洽的盘+包层辐射转移建模（论文提到后续工作将提供）。
- **样本限制**：
  - Class 0 源仅 3 个，无法单独统计比较；VLA 非探测 7 个盘，限制了短波与长波质量的完整对比。
  - 气体质量测量中未分辨的双星（如 04381+2540AB）被当作单源处理。
- **对比样本的跨方法局限**：
  - 与 AGE-PRO（C¹⁷O/热化学建模）和 Williams & Best（参数化温度结构）的对比受分子示踪剂和建模框架差异影响，可能引入数量级偏差。
- **环境解释的歧义**：
  - 猎户座与金牛座的差异被归因于恒星质量分布差异，但需假设两区域 IMF 相同；蛇夫座的异常低质量盘无法由区域年龄或成团性单独解释，具体初始条件未定论。
  - 跨区域对比的样本在观测灵敏度、波长覆盖上不完全一致（如英仙座是 8/10 mm 而非纯 9 mm），存在残余系统差。

**总体评价**：这是一项观测设计合理、统计处理得当、对早期盘质量测量具有重要参考价值的区域完整普查。其核心贡献在于提供了金牛座 Class 0/I 盘的统一尘埃+气体质量基准，揭示了跨区域环境差异和早期盘演化多样性。但由于辐射转移建模和尘埃假设的固有不确定度，尘埃质量的绝对值、气体-尘埃比的精确定标仍需未来更高分辨率、更多频率和更完善的热化学建模来收敛。
