## 摘要
在TESS时代，系外行星的后续观测和确认已成为一项大规模社区工作。在8000多个TESS系外行星候选体中，只有约八分之一得到确认，天文学家需要灵活的软件，以便利用来自多台望远镜和仪器的数据表征多种不同类型的系统。在这项工作中，我介绍了Alfred（用于稳健系外行星探测的卓越库），这是一个用于系外行星探测和确认的开源Python包。Alfred设计灵活且易于使用，允许用户为任意系外行星系统拟合凌星和径向速度数据。该代码已在GitHub（https://github.com/maxkroft/Alfred）上以MIT许可证发布，并可通过pip安装，文档正在积极开发中（https://alfred-exoplanets.readthedocs.io/en/latest/index.html#）。

## Abstract
In the era of TESS, exoplanet follow-up and confirmation have become a massive community effort. With only about an eighth of the over 8,000 TESS exoplanet candidates confirmed, astronomers need flexible software to allow them to characterize many different kinds of systems with data from multiple telescopes and instruments. In this work, I present Alfred (the Awesome Library For Robust Exoplanet Detection), an open-source Python package for exoplanet detection and confirmation. Alfred is designed to be flexible and easy to use, allowing users to fit transit and radial velocity data for an arbitrary system of exoplanets. The code is released under an MIT license on GitHub (https://github.com/maxkroft/Alfred ) and is installable via pip, with documentation under active development (https://alfred-exoplanets.readthedocs.io/en/latest/index.html# ).
