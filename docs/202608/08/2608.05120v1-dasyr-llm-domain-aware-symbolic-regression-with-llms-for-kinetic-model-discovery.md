## 摘要
动力学模型发现是化学工程中的一个核心挑战，因为准确的速率表达式对于理解和控制化学与生物过程至关重要。符号回归（SR）已成为识别可解释动力学模型的一种强大数据驱动方法，但通常在没有领域知识的情况下运行，常常探索物理化学上不合理的模型。大型语言模型（LLMs）为将领域专业知识注入这一搜索过程提供了有前景的途径。在此，我们引入了一个LLM引导的SR框架，将LLM模块嵌入迭代SR算法中，用于自动化动力学模型发现。在每次迭代中，LLM扮演两个角色：（1）对最佳SR候选模型进行定性物理化学评论，（2）在SR生成模型和嵌入的化学知识指导下提出新的候选速率表达式。我们在四个复杂度递增的计算机模拟案例研究上评估了我们的框架，涵盖多相催化和生物过程系统。结果表明，与最先进的SR框架相比，LLM引导框架将识别真实模型的迭代次数减少了41.7-79.3%，并且在超过一半的引导运行中，LLM直接提出了正确的模型结构。在实际场景中，每次迭代通常需要新的湿实验，这转化为实验工作量的显著减少。两种方法在独立验证集上的预测性能相当，在所有案例研究中R²>0.98。消融研究表明，SR组件和LLM规模都对这一性能有所贡献，而缩小规模的LLM在很大程度上保持了发现效率。这些发现表明，LLMs可以有效地将领域知识注入科学模型发现中，为全自动、领域感知的动力学模型流水线铺平了道路。

## Abstract
Kinetic model discovery is a central challenge in chemical engineering, as accurate rate expressions are essential for understanding and controlling chemical and biological processes. Symbolic regression (SR) has emerged as a powerful data-driven approach for identifying interpretable kinetic models, but usually operates without domain knowledge, often exploring physicochemically implausible models. Large language models (LLMs) offer a promising avenue for injecting domain expertise into this search. Here, we introduce an LLM-guided SR framework, embedding an LLM module within an iterative SR algorithm for automated kinetic model discovery. The LLM performs two roles at each iteration: (1) a qualitative physicochemical critique of the best SR candidates, and (2) the proposal of new candidate rate expressions guided by the SR-generated models and embedded chemical knowledge. Our framework is evaluated on four in silico case studies of increasing complexity, spanning heterogeneous catalysis and bioprocess systems. Results show the LLM-guided framework reduces iterations to identify the ground-truth model by $41.7-79.3\%$ versus a state-of-the-art SR framework, with the LLM directly proposing the correct model structure in over half of the guided runs. In practical settings, where each iteration typically requires a new wet-lab experiment, this translates into a substantial reduction in experimental effort. Predictive performance on an independent validation set is equivalent between both approaches, with $R^2>0.98$ in all case studies. Ablation studies indicate that both the SR component and the LLM scale contribute to this performance, with a reduced-size LLM largely retaining discovery efficiency. These findings demonstrate that LLMs can effectively inject domain knowledge into scientific model discovery, paving the way toward fully automated, domain-aware kinetic modelling pipelines.

### 二、方法论

**核心思想**：将 LLM 作为迭代发现循环内的“知识向导”，同时扮演两个角色：
1. **批判者**：对当前 SR 产生的最优候选模型进行定性物理化学合理性评估；
2. **生成者**：基于批判结果和自身化学知识，提出新的候选速率表达式。

**框架总体流程（基于 ADoK-S 骨干，共 9 个步骤）**：

1. **数据生成**：从 ground-truth 机理模型仿真生成初始浓度-时间数据（2 个初始条件下的实验，30 个采样点，噪声 σ=0.1）；
2. **浓度轨迹 SR**：使用 PySRRegressor 对每个物种的浓度轨迹拟合符号表达式 h(t)，并基于 AIC 选择最优轨迹模型；
3. **模型选择（浓度级）**：通过 AIC 选择每个物种、每个实验的最佳浓度模型；
4. **求导估计速率**：对拟合的浓度轨迹解析求导，得到反应速率的估计值；
5. **速率 SR**：以估计的速率作为回归目标、以测量浓度作为输入变量，运行符号回归搜索候选速率表达式；
6. **参数估计**：对 SR 产生的速率模型，通过 ODE 积分 + L-BFGS-B 多起点（20 个随机初始点）优化进行参数精修；
7. **LLM 模块**（本框架的核心创新）：
   - **Step 1（批判）**：LLM 接收 top-5 个 SR 候选模型的符号结构、参数值、NLL 和 AIC 值，输出对每个候选模型的定性物化合理性分析；
   - **Step 2（提出）**：LLM 基于 Step 1 批判结果和系统化学知识，提出 ngen=3 个结构上非重复的候选方程，并附机理说明。
   - 该模块以 nLLM=3 个并行实例运行（Qwen3-14B），产生最多 9 个 LLM 候选，再进行与 SR 候选相同的参数估计与 AIC 评估；
8. **模型选择（速率级）**：对所有候选（SR + LLM 提出）计算 AIC，排序选择最优模型；若未达到 ground-truth，则 Top-2 模型进入 MBDoE；
9. **MBDoE（基于模型的设计）**：通过最大化 Top-2 模型预测轨迹之间的差异（Hunter-Reiner 准则），优化下一实验的初始条件，生成新实验数据，并入数据集，回到第 1 步。

**关键公式**：
- 系统动力学：Ċ(t) = f(C(t))；
- 参数估计目标：最小化模拟轨迹与实验数据的 SSE；
- NLL 计算（结合独立估计的物种方差 σi² 与高斯误差假设）；
- AIC = 2·NLL + 2d（d 为参数数量）；
- MBDoE 优化准则：C0^(new) = argmax ∫ || Ĉ_m1(τ) − Ĉ_m2(τ) ||² dτ。

**关于 LLM 设计的关键决策**：将“批判”与“提出”分离为两步，比直接让 LLM 提出新候选更有效；使用自由文本输出而非结构化 JSON，保留推理灵活性（但带来人工解析的代价）。

   - 无数据访问（仅看候选模型结构、参数和指标）；
   - 有原始实验数据访问（额外输入浓度-时间原始数据）。
   每个变体 2 次运行，共 4 次。
2. **Reduced-Size LLM（小模型）**：用 Qwen3-8B 替代 Qwen3-14B，其余保持不变。共 4 次运行。

**算力与资源描述**：论文在“Computational Setup”明确说明，所有实验顺序执行，LLM 模块（Qwen3-14B）运行于帝国理工 HPC 集群，其余组件在本地工作站（Intel Core i9-12900，16 核 24 线程，16GB RAM）。但**文中未明确说明 GPU 型号、数量及训练时长**（由于使用的是开源预训练 LLM 而非自训练模型，因此不存在训练时长；只有推理开销，报告为每次迭代 293–998 秒不等）。

### 四、实验数量与充分性

**总体实验规模**：
- 主实验：4 案例 × 2 算法 × 4 次重复 = **32 次完整发现运行**；
- 消融实验：LLM-Only 4 次 + Reduced-Size LLM 4 次 = **8 次运行**；
- 每次运行独立记录：迭代次数、模型结构、AIC、参数置信区间、计算时间等；
- 验证集评估：每种模型在 120 个独立初始条件下的 MAE、MSE、R²。

**充分性评估**：
- **优点**：每个案例和算法组合做了 4 次独立重复，能够给出均值、方差和标准误差，支持迭代减少比例的统计对比；消融设计合理，能分离 SR 组件、LLM 规模和实验数据访问的作用；验证集设计包含外推区间，评估了模型泛化能力。
- **不足与潜在偏差**：
  - 每个配置只有 4 次重复，样本量较小，统计功效有限；
  - 三个案例（甲苯加氢、N₂O 分解、异构化）为文献中的经典动力学系统，**LLM 可能在预训练中接触过这些反应**，存在记忆偏差风险。论文承认无法排除这一可能性，但提供了部分证据（细菌生产案例为改编系统，LLM-Only 消融表现不佳）支持“主要增益来自 SR 与 LLM 互动而非记忆检索”的解释；
  - 消融实验仅在单一案例上执行，结论的通用性有限；
  - “with data”的 LLM-Only 变体提供了额外信息，可比性受限。

### 五、主要结论与发现

1. **迭代效率显著提升**：DASyR-LLM 相比基线 SR 将识别 ground-truth 模型所需迭代次数减少 **41.7%–79.3%**（按案例），且迭代次数直接对等于实验次数，意味着**湿实验成本大幅降低**。
2. **LLM 直接提出正确模型的频率高**：在 16 次 LLM 引导运行中，**9 次**最终模型由 LLM 直接提出（超过一半）；其余运行中 LLM 引导搜索向正确功能形式收敛。
3. **复杂度越高、增益越显著**：在基线最挣扎的模型（N₂O 分解、细菌生产）中增益最大（73.7%、79.3%）；在简单异构化案例中增益较小（41.7%）。
4. **预测性能不牺牲**：两算法在所有案例的验证集 R² 均 > 0.98（通常在 0.99 以上），分布相似，说明**加速发现不以损失模型精度为代价**。
5. **可解释性增强**：LLM 每轮输出机理层面上的定性评论，能明确指出候选模型的结构缺陷（如逆浓度依赖不符 Monod 假设、正产物抑制项不合理等），过滤物理上不一致的候选。
6. **消融结论**：
   - 移除 SR（LLM-Only，无数据）导致收敛可靠性下降（1/2 次失败、1/2 次 6 轮），说明 SR 提供的数据接地候选结构对 LLM 推理至关重要；
   - 提供原始数据可部分补偿 SR 缺失，但属于额外信息，可视为上限情景；
   - Qwen3-8B 保留了大部分发现效率（2–5 轮收敛），显示框架对 LLM 规模有较好鲁棒性。

### 六、优点

- **概念创新**：首次将 LLM 定性机理评估与候选生成两个角色同时嵌入 SR–参数估计–AIC–MBDoE 闭环，填补了现有文献中“LLM 仅做生成器或仅做评估器、且不与 MBDoE 结合”的空白。
- **可复现性**：所有代码与数据开源（Zenodo DOI），LLM 配置、提示模板完整公开，逐轮 LLM 输出记录在仓库中。
- **实验设计严谨**：统一实验预算、统一初始条件、多重复运行、统计显著性检验、独立验证集（含外推区域），控制变量清晰。
- **框架通用性**：LLM 模块作为插件嵌入，不改变底层 SR 或 MBDoE，理论上可适配不同 SR 引擎；结构上可推广至 PDE、更大反应网络等。
- **实际价值导向**：以“实验迭代次数”为核心指标，直接对接湿实验室成本瓶颈，实用性强。
- **消融设计完整**：分离了 SR 组件、LLM 规模和 LLM 信息访问权限三个变量，对框架各部分的贡献给出了清晰证据。

### 七、不足与局限

- **计算开销增加**：
  - 每次迭代 LLM 推理耗时 293–998 秒（依案例和轮次波动），显著高于基线单次迭代的 SR 成本（约 100–700 秒）；
  - 额外的 LLM 候选参数估计（20 起点多起点优化）也增加单次迭代耗时；
  - 虽然在总迭代减少下总时间增益在多数案例中仍成立，但在增量较小的案例（如异构化）中总耗时可能高于或持平基线。
- **人工介入**：LLM 输出的自由文本表达式需要**手动解析**为结构化格式，尚未实现全自动化。论文明确了这一点，但将其视为未来工作方向。
- **参数估计不保证全局最优**：多起点 L-BFGS-B 方法本身不保证收敛到全局最优；对 LLM 候选（无初始参数估计）尤甚，可能因不良初始化导致结构正确的模型被 AIC 放弃，从而影响发现效率。
- **数据假设的理想化**：所有实验使用合成数据，假设所有物种均可测量、噪声为零均值高斯、无系统偏差或缺失观测，在真实湿实验室中这些假设可能不成立。
- **潜在记忆偏差**：三个文献案例的系统可能出现在 LLM 预训练语料中，尽管论文提供了证据支持“SR-LLM 协作是增益主因”的解读，但无法完全排除先验暴露的贡献。
- **缺乏早期停止准则**：未采用 AIC 差异阈值等停止准则；在真实应用中（ground-truth 未知）如何判断“模型已足够好”仍是开放问题。
- **消融和归纳范围有限**：消融仅基于单一案例；组件贡献结论对更广泛反应网络的泛化性未验证。
