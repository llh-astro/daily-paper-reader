## 摘要
混沌巡游（CI）由K. Ikeda、I. Tsuda和K. Kaneko等人在20世纪90年代初引起关注，是一种现象，其中动力系统中的轨迹经历准吸引子附近的有序运动阶段，并穿插其间的混沌过渡。发现CI的可能映射包括耦合映射格（CML）和全局耦合一维混沌映射（GCM）。我们使用数值方法和图算法研究此类映射。具体而言，我们将状态空间划分为有限个紧子集的网格，并使用网格元素的多值映射来表示该映射。该映射可视为有向图，其中网格元素为顶点，它们之间的单个映射为加权边。这种设置提供了全局动力学的粗略视图，并为使用马尔可夫链和高效图算法研究动力学特征提供了机会。特别是，可以通过计算图中的强连通分量来找到不变集。对图转移矩阵的分析使得可以找到其平稳分布，并计算局部熵作为系统中扩张或不稳定性的度量。利用这些工具，我们提出了一种评估某个映射是否具有CI属性的算法，并将其应用于动力系统：一个全局耦合的逻辑斯蒂映射系统和一个CML系统的变体，我们对其进行了大范围参数的计算。

## Abstract
Chaotic itinerancy (CI), brought to attention, among others, by K. Ikeda, I. Tsuda and K. Kaneko in the early 1990s, is a phenomenon in which trajectories in a dynamical system experience periods of ordered motion near quasi-attractors interspersed with chaotic transitions between them. Possible maps in which CI was found include coupled map lattices (CML) and globally coupled one-dimensional chaotic maps (GCM). We study such maps using numerical methods and graph algorithms. Specifically, we partition the state space into a finite grid of compact subsets, and we represent the map using a multivalued mapping of grid elements. This mapping can be perceived as a directed graph, with grid elements as vertices and individual mappings between them as weighted edges. This setup provides a coarse view of global dynamics and opens the opportunity for using Markov chains and efficient graph algorithms to study dynamical features. In particular, invariant sets can be found by computing strongly connected components in the graph. Analysis of the transition matrix of the graph makes it possible to find its stationary distribution and to compute local entropy as a measure of expansion or instability in the system. Using these tools, we propose an algorithm for assessing whether a certain map possesses the CI property and show its application to dynamical systems: a globally coupled system of logistic maps and a variant of a CML system for which we conduct computations for a large range of parameters.

- **方法可行性**：提出的集合导向框架能够以量化的方式自动识别 CI 的关键特征——平稳分布揭示准吸引子位置，谱间隙提示亚稳态存在，局部熵区分有序/无序区域，SCC 与流出量刻画准吸引子结构与不稳定性。
