## 摘要
系外行星的反射光偏振测量法可以约束并消除大气特性的简并性，而对碎片盘的偏振光观测则能够表征尘埃颗粒的性质。罗曼日冕仪仪器的尽力而为偏振模式将能够使用混合里奥日冕仪（HLC）和整形光瞳日冕仪（SPC）对行星系统进行多波长观测。本文概述了罗曼日冕仪偏振模式的观测规划、模拟和数据处理流程。作为模拟和数据处理的一项初步测试，使用corgisim结合估计的观测参数生成了HLC模式下碎片盘HD 172555的偏振观测序列数据集，并使用corgidrp进行了数据处理，纳入了所有相关的噪声因素和校准产品。目前，corgidrp中使用的是模拟校准产品；在未来的更新中，这些将被模拟校准产品所取代。

## Abstract
Reflected-light polarimetry of exoplanets constrains and resolves degeneracies in atmospheric properties, while polarized light observations of debris disks enable the characterization of dust-grain properties. The best-effort polarimetric mode of the Roman Coronagraph Instrument will be able to perform multi-wavelength observations of planetary systems using both the Hybrid Lyot Coronagraph (HLC) and the Shaped Pupil Coronagraph (SPC). This paper presents an overview of observation planning, simulations, and data reduction procedures for the polarimetric mode of the Roman Coronagraph. As an initial test of simulation and data reduction, a dataset of polarimetric observing sequences for the debris disk HD 172555 in HLC mode was generated using corgisim with estimated observation parameters, and data reduction was performed using corgidrp, incorporating all relevant noise factors and calibration products. Currently, mock calibration products are used in corgidrp; these will be replaced with simulated calibration products in future updates

# 罗曼日冕仪社区参与计划：偏振模式的观测规划与数据处理——论文总结

## 1. 核心问题与研究动机

- **科学背景**：探测和表征绕类太阳恒星运转的行星是行星天文学的主要目标之一，而系外行星的反射光偏振测量能够约束并消除大气性质的简并性；碎片盘的偏振光观测则可表征尘埃颗粒的散射与几何特性。
- **关键难点**：尘埃颗粒属性对辐射传输过程的影响复杂且高度简并，仅有总强度观测难以单独约束各参数。实验室测量表明，线偏振分数的测量比总强度观测更有效地约束颗粒属性。
- **仪器背景**：罗曼日冕仪（Roman Coronagraph, RC）搭载于南希·格雷斯·罗曼太空望远镜，计划于2026年8月30日发射。其硬性技术要求（TTR5）仅为在波段1（575 nm）使用混合里奥日冕仪（HLC）完成技术演示，但仪器具备"尽力而为"（best-effort）的多波长偏振观测能力。
- **核心目标**：使用HLC和整形光瞳日冕仪（SPC）进行多波长偏振观测，以深化对行星系统架构与组成的理解，特别是验证一项早期科学需求——"对偏振分数≥0.3的碎片盘绘制线偏振图，不确定度<0.03"。

## 2. 方法论

### 2.1 偏振观测序列设计

- 仪器采用两个Wollaston棱镜（POL0和POL45），将入射光分成四个正交分量：I₀、I₉₀、I₄₅、I₁₃₅。
- 观测序列（图2）流程：
  - Roll A位置观测参考星（POL0和POL45两种配置）
  - 机动至目标星，在交替滚动角（Roll A、Roll B）下用两种Wollaston配置观测目标星
  - 在Roll B位置再次观测参考星
  - 可增加额外目标滚动角
  - 序列末尾进行偏振校准观测
- 在每个访问点获取卫星斑点（satellite spots）用于帧对齐。
- 参考星观测支持基于参考星的差分成像（RDI）或偏振约束的参考星差分成像（PCRDI）后处理。

### 2.2 偏振校准（四类）

- **偏振平场**：使用POL0和POL45在位时的平场观测，源天体为天王星或海王星。
- **Mueller矩阵**：通过观测偏振和非偏振标准星，量化望远镜及日冕仪引起的偏振效应，覆盖所有科学配置（中性密度滤光片、各种焦平面掩模、不同滤光片）。
- **偏振绝对流量校准**：使用亮/暗光度标准星的Wollaston观测，将探测器数字数转化为物理流量单位。
- **参考星与目标星偏振校准**：使用中性密度滤光片的非遮挡观测，估计并扣除中心恒星偏振。

### 2.3 曝光时间估计

- 基于Nemati et al. (2023)的RDI信噪比公式，扩展至偏振模式：

  \[
  SNR_{pol} = \frac{r_{pl}\,t\,p}{\sqrt{r_{n}^{pol}\,t + f^2_{\Delta I}\,r^2_{sp}\,t^2 + C^2_{pab}\,t^2}}
  \]

  其中 \(p\) 为偏振分数，\(r_{pl}\) 为行星信号计数率，\(r_n^{pol}\) 为双孔径噪声（因两孔径测量而加倍），\(C_{pab}\) 为偏振散斑对比项。
- 反转公式得到所需积分时间：

  \[
  t = \frac{SNR^2_{pol}\,r_n^{pol}}{(r_{pl}\,p)^2 - SNR^2_{pol}\,(f^2_{\Delta I}\,r^2_{sp} + C^2_{pab})}
  \]

- 该模型已集成至corgietc工具中，用于估算不同偏振分数下的积分时间。

### 2.4 模拟流程（corgisim）

- 对点源（行星）输入斯托克斯矢量 [I, Q, U, V]；对延展源（碎片盘）输入4×n×n的斯托克斯立方体（由MCFOST辐射转移软件生成）。
- 处理链：输入Stokes立方体 → 按星等和盘对比度缩放 → 乘以仪器Mueller矩阵 → 乘以Wollaston棱镜Mueller矩阵（POL0得I₀/I₉₀，POL45得I₄₅/I₁₃₅）→ 与仪器点响应函数卷积 → 生成EXCAM全帧L1图像。

### 2.5 数据缩减流程（corgidrp）

管线依次执行 L1 → L2a → L2b → L3 → L4 → TDA 六个层级：

- **L1→L2a**：与总强度图像相同的处理（偏置扣除、非线性校正、宇宙射线检测）。
- **L2a→L2b**：同总强度流程，但平场使用偏振平场；还包括计数→电子转换、电子倍增增益归一化、暗场扣除、电荷转移效率校正、坏像素校正。
- **L2b→L3**：分离四偏振态，提取子阵列，构建图像立方体；按曝光时间归一化；生成天球坐标系（WCS）。
- **L3→L4**：帧对齐、扣除中心恒星偏振（使用非遮挡观测估计）、估计Stokes参数 [I, Q, U, V]、旋转至北向上东向左、PSF扣除、应用Mueller矩阵校准。
- **L4→TDA**：对探测到的伴星计算偏振分数、偏振信噪比（pSNR）和偏振位置角；对碎片盘计算方位角Q和U分量（Qφ、Uφ）及偏振强度。
