## Abstract
The ability to derive the governing equations of a dynamical system from data is essential for prediction and control across many scientific fields. Two challenges, however, are the expansion of candidate terms when reducing higher-order equations to first-order form and noise from estimating derivatives. We propose Higher-Order-KANDy, which addresses both problems by using delay and derivative ("jet") embeddings of the original data with derivative-ordered Kolmogorov-Arnold Networks for Dynamics (KANDy) layers stacked into a machine learning architecture. Compared with SINDy and WSINDy on noisy data, Higher-Order-KANDy learns governing equations without a candidate library (e.g., recovering the full-period $-\sin(u)$ with nothing named in advance), natively for higher-order systems, and holds the correct term structure as noise grows, selecting the exact active set on every seed at noise levels up to 7.5% where an oracle weak-form regression admits a spurious term, though the oracle remains the more accurate coefficient estimator. We leverage the relationship between delay and differential embeddings, along with the Kolmogorov-Arnold representation theorem, to construct a delay-to-jet map and learn it as a Kolmogorov-Arnold network to preserve derivative structure and provide meaningful terms that appear in the governing equation. In our synthetic benchmarks, this construction recovers equations in the presence of coarse sampling and noise.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究目标**：从数据中自动发现动力系统的控制方程，使其可用于预测与控制，是物理、工程、生物等领域的基础问题。
- **两大现存瓶颈**：
  - **候选库膨胀**：将高阶 ODE/PDE 改写为一阶系统进行稀疏回归时，会引入额外变量，导致候选词项（dictionary）组合式爆炸，既损害数值条件数又损害可解释性，并预设了已知的方程结构。
  - **导数噪声放大**：从含噪数据估计导数（尤其是二阶、三阶导数）会严重放大噪声，使稀疏回归系数漂移、前向积分发散。
- **现有方法的局限**：
  - **SINDy / PDE-FIND**：依赖用户指定候选库，且依赖逐点数值微分。
  - **WSINDy**：用弱形式（线性泛函 + 方差缩减）缓解导数噪声，但库的选取仍是瓶颈——库太小无法表达方程，库太大破坏条件数。
  - **KANDy**：将 KAN 塌缩为单层、其边直接对应方程加性项，但仅针对**一阶** ODE。
- **整体含义**：论文提出 **Higher-Order-KANDy**，将 KANDy 原生扩展到高阶系统，并借助延迟嵌入与微分嵌入（jet）之间的关系，把"延迟→jet"映射学习为 Kolmogorov-Arnold 网络，从而在**无需候选库**的前提下、**原生按阶**发现方程，且对粗采样和噪声更稳健。

## 2. 方法论

### 核心思想
- 将 KANDy 视为一个**更深网络的单层**：第 $n$ 层对应第 $n$ 阶导数 $x^{(n)}$，形成一条"单导数 KAN 模块链"，每条可学习的一元边（univariate edge）直接读出为控制方程中的加性项。
- 关键洞见：延迟嵌入（delay embedding）与微分嵌入（differential/jet embedding）是同一吸引子的两个坐标图（chart），二者之间的转换映射天然适配 Kolmogorov-Arnold 两层表示。

### 关键技术细节
- **架构（图 1 / 图 3）**：
  - **第 1 层（lifting，1-KANDy）**：从延迟向量 $y(t) = (x(t), x(t-\tau), \dots, x(t-(m-1)\tau))$ 学习未观测的速度 $\hat{x}'$，等效于一个数据自适应的有限差分算子。
  - **第 2…n 层（equation layers，k-KANDy）**：消费由已预测导数堆栈 $D_k = \{x, \hat{x}', \dots, \hat{x}^{(k-1)}\}$ 构建的特征库 $\Theta_k$，预测下一阶导数：$\hat{x}^{(k)}(t) = \sum_j \phi_{k,j}(\theta_{k,j})$。
  - 当库为空时退化为**自由形式加性发现**（free-form additive discovery），如 $x^2$ 从边形状读出而非作为库列提供。
  - 单个方程层只能表示**加性可分**的右端项；耦合项（如 KdV 的 $u u_x$、Bouc-Wen 的 $|\dot{x}|z^3$）需作为复合特征 $\theta_j$ 提供。
- **两种前端（front end）**：
  - **延迟提升（delay lift）**：基于 Takens 嵌入定理，从标量观测重建完整状态（含隐藏非导数状态）。
  - **Jet 嵌入（jet embedding）**：对场数据用一个二维张量积平滑样条 $S(x,t)$（次数 5×5，平滑强度 $\lambda = N\hat{\sigma}^2$）拟合，再对其解析求偏导得到整个 p-jet，从而避免逐点差分。
- **延迟→jet 映射的理论刻画（附录 S3）**：
  - 命题 S3.1：在延迟映射为嵌入的前提下，jet 在各采样率下均可辨识，$x^{(k)}(t) = (L_f^k h) \circ \Phi^{-1}(y_t)$。
  - 引理 S3.6：两样本延迟映射的混合偏导 $\partial^2_{y_1 y_2} G_{1,\Delta} = \frac{\Delta}{12} g''(y_1) + O(\Delta^2)$，说明非线性系统下**单加性层不足**，需要两层。
  - 命题 S3.11：延迟→jet 映射存在、是两图之间的同胚/微分同胚，并**恰好可表示为共享内层的两层 KAN**（形状 $m \to 2m+1 \to p+1$），且可用样条 KAN 一致逼近。
  - 推论 S3.12：提升误差线性传播到所发现定律的残差（$\leq (1+L\sqrt{n})\epsilon$）。
- **训练目标**：提升损失 + 方程损失（按目标方差归一化）的加权和；若系统完全可观可绕过提升层。

## 6. 主要结论与发现

- **原生高阶发现**：Genesio–Tesi 三阶系统仅从标量 $x(t)$ 恢复全部四个系数（误差约 8%），并自由积分复现混沌吸引子。
- **无需候选库**：自由形式边可恢复全周期 $-\sin(u)$（相关系数 $\rho \geq 0.952$），而多项式库方法在所有噪声水平下都只能命中 1/2 真实项（库覆盖不足，非选择失败）。
- **噪声下的支持集鲁棒性**：在 sine-Gordon 碰撞基准上，噪声水平 **≤7.5% 时每个种子都精确选出 $\{u_{xx}, \sin u\}$**；10% 时 5 个种子中 4 个精确。而 oracle WSINDy 从 3% 起即引入虚假线性项 $u$。
- **精度 vs 结构的分野**：oracle WSINDy（被直接喂入精确 $\sin(u)$ 列）在形式精度上始终更优；Higher-Order-KANDy 的优势在于**结构选择**和**无需列**。
- **PDE 与粗采样**：KdV 上 PDE-FIND 在噪声下系数崩塌并前向积分发散，而边读出退化更慢且能保持正确波形；Genesio–Tesi 在每周期两次采样时，oracle 调参的 Savitzky–Golay 损失 3/4 项，而学习到的延迟提升恢复全部四项至 1% 以内。
- **隐藏状态**：Bouc–Wen 隐藏记忆变量 $z$ 只能通过延迟提升重建（$R^2=1.00$），从瞬时坐标 $(x,\dot{x})$ 则无法表示（$R^2=0.23$）。
- **表示类结论**：密集采样下线性映射已最优；欠采样下只有**两层组合 KAN** 保持近精确（Lorenz $x'$：2 层 0.88 vs 加性 0.62 vs 线性 0.44 at $\Delta t=0.40$）；越过混叠墙后所有类都失效。

## 7. 优点

- **理论扎实**：将延迟/微分嵌入的图变换关系与 Kolmogorov-Arnold 表示定理结合，给出存在性（命题 S3.1/S3.11）、下界（引理 S3.6）、条件数与稳定性（命题 S3.3）以及误差传播（推论 S3.12）的完整逻辑链。
- **架构优雅且可解释**：每阶一个 KAN 层，边直接对应加性方程项，可逐一绘制、符号化识别，保留物理意义与单位。
- **真正的无库发现能力**：在未预先命名任何项的情况下恢复全周期 $-\sin(u)$，突破多项式库的覆盖限制。
- **抗噪与抗粗采样**：解析样条 jet 与学习到的延迟→jet 映射分别应对噪声与欠采样，并在实验中明确分离两种失效模式。
- **实验设计严谨**：对称审计协议、关闭稀疏先验、零对照边、独立噪声实现、多种子报告、前向积分外推、同导数后端对比等，减少混淆并提高可信度。
- **诚实性**：坦承 oracle 弱形式回归系数更准、无监督隐变量恢复仍开放、Symbolic-KAN 默认设置在部分情况下失效。
- **可复现性**：代码与实验在 GitHub 开源。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、训练时长，影响复现成本评估。
- **仅合成基准**：所有实验均为合成数据（ODE/PDE 仿真），缺乏真实实验数据或观测噪声/缺失机制下的验证。
- **系数衰减问题**：高噪声（5–10%）下自由形式边的系数显著衰减（如 $-0.79$、$-0.70$），影响定量精度；论文承认 oracle 更准。
- **库依赖仍存在**：当提供词库 $\Theta_k$ 时方程层假定其正确；库不当仍会误配动力学（虽比稀疏回归字典小）。
- **加性可分性限制**：自由形式方程层无法表示乘性耦合项（如 KdV 的 $u u_x$、Bouc-Wen 的 $|\dot{x}|z^3$），必须手工提供复合特征，削弱了"完全无先验"的主张。
- **隐藏状态依赖监督**：Bouc–Wen 的延迟提升是一个**监督探针**（对真值 $z$ 训练，$R^2=0.998$）；无监督隐变量仅形状对齐（Pearson 0.79，对齐 $R^2 \leq 0$

.90）；无监督条件下的隐变量重建仍为开放问题。
- **前端依赖超参**：延迟嵌入的 $m, \tau$ 需按系统选择（如 Genesio–Tesi $m=7$、Bouc–Wen $m=12$），论文虽提供启发式但仍需人工/扫描确定；采样率越接近混叠墙，所有表示类都失效，方法边界明确但适用域受限。
- **对比公平性存疑**：SINDy-KAN 无官方实现（自行重实现），Symbolic-KAN 采用默认设置且论文指出其在部分噪声下结构性失效，可能未给予同等调参预算；尽管作者给出了"结构性原因"解释，仍难以完全排除方法调参差异带来的优势。
- **种子重复偏少**：多数系统（Bouc–Wen、PDE 类实验）仅 3 种子，统计显著性有限；而 sine-Gordon 基准用了 5 种子 × 12 噪声水平，二者证据强度不对称。
- **稀疏先验被禁用**：论文在审计中刻意设 $\lambda=0$ 并指出 L1 会破坏恢复，这虽然强化了"无库"主张，但也意味着方法在需要稀疏性的场景下缺少可调机制，且与稀疏回归类方法的可比性更多体现在"结构"而非"稀疏"层面。
- **单位与量纲处理**：边读出保留了物理单位，但多阶导数堆栈的量纲尺度差异如何归一化、是否影响跨阶系数比较，论文着墨较少。
- **理论前提较强**：命题 S3.1/S3.11 依赖延迟映射为嵌入（Takens 条件），对含噪、有限样本、非平稳或强耗散系统，嵌入存在性与微分同胚假设未必严格成立，理论保证与实际鲁棒性之间存在缝隙。

## 9. 对后续工作的启示与改进方向

- **无监督隐状态发现**：当前 Bouc–Wen 的延迟提升依赖对真值 $z$ 的监督；将提升层与方程层的联合训练改为完全自监督（如最小化前向预测误差 + 一致性正则），是该方向最直接的开放问题。
- **复合特征自动构造**：自由形式层受加性可分性限制，未来可探索让 KAN 的第二层内层自动学习乘性/复合项（如 $u u_x$），或引入"乘积节点"扩展 Kolmogorov–Arnold 表示类，从而真正摆脱对手工复合特征的依赖。
- **系数精度的后处理**：鉴于高噪声下自由形式边系数衰减，可将 KANDy 的结构发现结果作为**列选择器**，再接一次 oracle 式弱形式回归（即"KANDy 选结构 + WSINDy 估系数"的两段式流水线），兼顾结构鲁棒性与定量精度。
- **自适应延迟参数**：用数据驱动准则（如互信息、虚假最近邻、嵌入维数估计）自动确定 $m, \tau$，减少人工扫描，并提升对采样率变化的适应性。
- **真实数据验证**：将方法推广到实验观测（如流体实验、生物时序、金融/气候数据），检验噪声结构非高斯、缺失值、非平稳等真实挑战下的表现。
- **与其他表示类的融合**：可探索 KAN 层与神经 ODE、符号回归、稀疏贝叶斯回归的结合，在保持可解释边读出的同时引入不确定性量化。
- **理论推广**：将延迟→jet 的两层 KAN 表示定理推广到部分观测的 PDE、多变量耦合系统及非自治情形，并给出有限样本下的误差界。

## 10. 总体评价

Higher-Order-KANDy 的核心贡献在于把"从延迟嵌入到微分嵌入"的坐标变换重新表述为一个**可学习的 Kolmogorov–Arnold 网络**，从而在同一架构内同时解决高阶导数的**表示**（按阶分层）与**估计**（样条 jet 或延迟提升）两个问题，并实现**无需候选库**的方程发现。其理论链条（存在性、下界、条件数、误差传播）完整，架构可解释性强，每阶一个 KAN 层、每条边对应一个加性项的读出方式保留了物理语义；实验设计上刻意分离导数估计与表示选择、关闭稀疏先验、使用零对照边与独立噪声实现，方法学严谨度较高。

其主要局限在于：**全部为合成基准**、**算力信息缺失**、**高噪声下系数衰减**、**加性可分性限制**、**隐藏状态重建仍依赖监督**，以及对**对比方法调参公平性**的潜在争议。这些并不否定其"结构发现优先"的定位——论文自己也坦承 oracle 弱形式回归在系数精度上更优，KANDy 的价值在于**不依赖列**且**抗噪/抗粗采样地选对支持集**。

总体而言，这是一篇**理论动机清晰、方法新颖、实验控制严谨但适用域边界明确**的工作。它把延迟/微分嵌入的几何关系与 KAN 表示能力结合，为高阶动力系统的无库符号发现提供了有说服力的新范式；若后续能在无监督隐状态、复合特征自动构造与真实数据验证上取得突破，其影响将从合成基准扩展到更广的科学发现场景。
