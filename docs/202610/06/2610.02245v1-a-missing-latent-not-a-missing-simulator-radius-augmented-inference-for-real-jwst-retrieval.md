## 摘要
摊销式基于模拟的推断（SBI）在辐射传输模拟器上训练后，能在合成詹姆斯·韦布空间望远镜（JWST）光谱上准确恢复系外行星大气，但在真实约化光谱上却会崩溃。该流后验在真实 WASP-39b 上崩溃（重要性采样有效样本量（ESS）=1，最佳拟合 χ²/N=301）。这类失败通常被归咎于缺失前向模型物理，但首先用嵌套采样排除这些因素（温度梯度、SO₂不透明度以及高保真不透明度集）后，拟合结果保持不变，这意味着崩溃并非源于模拟器误设，而是源于一个缺失的隐变量：行星半径。为解决这一问题，我们构建了 MIRAGE，这是一种半径增强的流匹配后验，通过重要性采样和最优传输映射，针对独立的嵌套采样参考进行校准，从而对真实 WASP-39b 给出物理上合理且与文献一致的反演（χ²/N 从 301 降至 0.06）。同一方法无需改动即可迁移至两台仪器和三个真实 JWST 目标，其中包括一条从原始 Mikulski Archive for Space Telescopes（MAST）数据端到端自行约化的光谱。这一教训具有跨领域意义：模拟器所编码但推断所忽略的隐变量，可能被误认为是模型误设。

## Abstract
Amortized simulation-based inference (SBI), which is trained on radiative-transfer simulators, recovers exoplanet atmospheres accurately on synthetic James Webb Space Telescope (JWST) spectra but collapses when it comes to real reduced spectra. The flow posterior collapsed on real WASP-39b (importance-sampling effective sample size (ESS) = 1, best-fit \c{hi}2/N = 301), and such a failure is usually blamed on missing the forward-model physics, but ruling these levers out with nested sampling first (a temperature gradient, SO2 opacity, and a high-fidelity opacity set) leaves the fit unchanged, meaning the collapse is not from the simulator misspecification but instead from a missing latent, the planet radius. To fix this, we build MIRAGE, a radius-augmented flow-matching posterior calibrated against an independent nested-sampling reference with importance sampling and an optimal-transport map, which yields a physical and literature-consistent retrieval of real WASP-39b (with \c{hi}2/N from 301 to 0.06). This same method transfers unchanged across two instruments and three real JWST targets, including one spectrum self-reduced end-to-end from raw Mikulski Archive for Space Telescopes(MAST) data. The lesson is cross-domain, as a latent the simulator encodes but the inference omits can masquerade as misspecification.

# 论文总结：缺失的隐变量，而非缺失的模拟器——用于真实 JWST 反演的半径增强推断

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：摊销式基于模拟的推断（SBI）与神经后验估计（NPE）已成为科学逆问题的标准工具——在模拟器抽样上训练条件密度估计器，测试时即可近乎即时地获得后验。但这类估计器的可信度完全取决于模拟器，在真实数据上会**静默失败**：当前向模型相对仪器发生误设时，后验会自信地集中在错误位置。
- **具体场景**：JWST 透射光谱学中，基于辐射传输前向模型训练的机器学习反演器在**合成光谱上准确**，但在**真实约化光谱上性能退化**。
- **关键现象**：在真实 WASP-39b 上，流后验崩溃——重要性采样有效样本量 ESS = 1，最佳拟合 χ²/N = 301，后验"自信但错误"地收敛到近乎寒冷的平坦大气。
- **核心追问**：真实数据上的崩溃究竟是**前向模型保真度问题**（缺失分子、不透明度表等），还是**可辨识性问题**？
- **论文结论性主张**：崩溃并非模拟器误设，而是**缺失了一个隐变量——行星半径**。模拟器编码了该因素，但推断却将其遗漏，使一个良定的前向模型看起来像是误设的。这是一个跨领域的教训。

## 2. 方法论

### 核心思想
构建 **MIRAGE**（Multi-Instrument Retrieval with Adaptive Generative Estimation）：在推断参数中加入行星半径，用域随机化光谱训练流匹配后验，再用最优传输映射与重要性采样将其校准到独立的嵌套采样参考上。

### 关键技术细节

- **前向模型与训练数据**
  - 使用 **TauREx 3** 生成训练光谱，映射大气参数向量到透射光谱的凌星深度。
  - 参数化 θ = [Rp, T, log X₁, …, log X₅]：行星半径、等温大气温度、五种分子（H₂O、CO₂、CH₄、CO、NH₃）的对数丰度，共 **7 维**。
  - 不透明度来自 **ExoMolOP** 数据库；光谱计算在与真实 JWST 观测**相同的波长网格**上，避免插值/重网格化引入偏差，从而将噪声与标定失配（而非波长网格失配）作为研究对象。
  - **域随机化策略**：真实仪器系统误差在波长间相关而非 i.i.d.，因此对每条训练光谱注入**结构化相关噪声**。观测模型为 x = f_TauREx(θ) + ε，ε ~ N(0, Σ(φ))；协方差由白噪声与两部分相关结构组成：
    - 平方指数（SE）核——模拟平滑的探测器漂移；
    - Ornstein–Uhlenbeck（OU）核——模拟长程 1/f 相关；
    - 参数随机范围：σ ~ U(0.05, 0.30)，ρ ~ U(0.3, 0.8)，ℓ_SE ~ U(0.02, 1.00) μm，ℓ_OU ~ U(0.05, 3.00) μm。
  - 协方差不仅注入光谱，还作为**条件输入**传给网络（协方差嵌入）。
  - 训练集：N = **28,000** 对 (θ, 含噪光谱, Σ)，另有 4,000 对验证。

- **半径增强的流匹配后验（FMPE）**
  - 在 **fm4ar** 骨干网络上使用流匹配估计后验，以高斯基分布沿线性路径传输到后验。
  - 条件流匹配目标（论文式 1）：在 t~U[0,1]、z₀~N(0,I) 上，最小化速度场 v_ψ((1−t)z₀ + tθ, t, c(x)) 与 (θ − z₀) 之间的均方误差。
  - **唯一结构改动**：推断向量 θ 中加入了行星半径 rp（式 2），使网络能吸收约 3% 的凌星基线偏移，而非扭曲大气参数来补偿。

- **校准（重要性采样 + 最优传输）**
  - 真实数据上流提议 q(θ|x) 过度离散，用**重要性采样**重加权逼近真实后验：wᵢ ∝ p(x|θᵢ)p(θᵢ)/q(θᵢ|x)，并监控 ESS = 1/Σwᵢ²。
  - 用**最优传输映射** T* 将流提议传输到独立嵌套采样参考 p_NS（式 4）：T* = argmin ∫‖θ − T(θ)‖² q(θ|x)dθ，约束 T#q = p_NS。
  - 校准样本 θ̃ᵢ = T*(θᵢ)，用嵌套采样值在标定区间内的覆盖率衡量质量（受 RoPE 对误设的最优传输处理启发）。

## 3. 实验设计

### 数据集 / 场景
- **三个真实 JWST 目标**，跨行星类别、仪器与数据来源：

  - **WASP-96b**（NIRISS SOSS），**从原始 MAST 数据端到端自行约化**（exoTEDRF + batman 光变曲线拟合），非已发表光谱。
  - **K2-18b**（冷亚海王星，NIRISS SOSS），使用 Madhusudhan et al. 2023 光谱。
- 嵌套采样参考用 TauREx + Nestle 采样器（300 live points）计算。

### Benchmark 与对比
- **基准**：独立嵌套采样参考 p_NS（用于校准与覆盖率评估）。
- **诊断性对比（排除前向模型保真度）**：在真实 WASP-39b 上，先加候选物理杠杆再用嵌套采样重新拟合：

  - 加入 SO₂ 不透明度；

## 6. 主要结论与发现

- **诊断结论**：真实数据上的 SBI 崩溃是**可辨识性失败**而非前向模型误设。加入温度梯度、SO₂ 不透明度、高保真不透明度集后，拟合结果几乎不变（χ²/N 约 38.4，寒冷平坦解持续存在）；而**释放行星半径**后，χ²/N 从 38.44 降至 **0.76**，拟合回到温暖（~600 K）、富水（log H₂O ≈ −3.2）、与文献一致的大气。
- **方法效果**：半径增强 + OT 校准后，真实 WASP-39b 的最佳拟合 **χ²/N 从 301 降至 0.06**，覆盖率从 **2/7 升至 7/7**，恢复的半径与丰度匹配嵌套采样锚点及已发表反演。
- **迁移性**：同一方法**无需改动**在三个真实目标上均有效，半径恢复接近文献值（WASP-39b: 1.227 vs 1.28；WASP-96b: 1.196 vs 1.20；K2-18b: 0.232 vs 0.24），覆盖率分别为 7/7、7/7、6/7；自约化光谱上的反演强度与已发表光谱相当，且恢复了 WASP-96b 的 1.4 μm 水特征。
- **负面结果**：CycleGAN 域翻译（MMD ≈ 1.22）未优于结构化随机化；协方差条件化在合成 ABC 基准上有效（0.587 → 0.687）但**无法迁移到真实目标**，因为真实仪器噪声超出训练噪声模型覆盖的分布。
- **跨领域教训**：模拟器编码但推断遗漏的隐变量，会让良定的前向模型伪装成误设；修复之道是**可辨识性**（补隐变量），而非保真度（改模拟器）。

## 7. 优点

- **诊断方法论清晰有力**：用独立于摊销网络的嵌套采样逐一排除候选物理杠杆，将"保真度 vs 可辨识性"的模糊归因转化为可证伪的实验，逻辑链条完整。
- **改动极简、收益显著**：相对标准 FMPE 的**唯一结构改动**是加入半径这一维，却带来 χ²/N 从 301 到 0.06 的质变，说明问题定位准确而非靠架构堆叠。
- **训练分布设计有针对性**：域随机化用 SE + OU 混合核建模相关噪声，并将协方差作为条件输入，直接针对真实系统误差的分布特性。
- **校准方案有理论依据**：重要性采样重加权 + 最优传输映射到嵌套采样参考，思路受 RoPE 对误设的处理启发，兼顾了摊销效率与统计严谨。
- **迁移验证维度丰富**：跨行星类别、跨仪器、跨数据来源（含端到端自约化），且方法完全不变，强化了通用性主张。
- **学术诚实度高**：Section 5 明确列出摊销差距、噪声条件化不可迁移、CycleGAN 无增益等边界，不回避负面结果与覆盖率的构造性局限。

## 8. 不足与局限

- **摊销差距未消除**：校准仍需为**每个新目标**跑一次独立的嵌套采样锚点，OT 映射（而非流本身）才是把后验拉到参考上的关键，因此并未真正实现"零成本摊销"。
- **覆盖率证据的循环性**：覆盖率是在与 OT 映射拟合目标相同的嵌套采样参考上评估的，论文承认这只能说明"传输被求解了"，而非"网络恢复了真实后验"；真正独立于映射的证据只有与文献值吻合的半径。
- **噪声条件化不迁移**：协方差条件化在合成 ABC 基准上有增益，但在所评估的单一真实目标上无效，因为真实仪器噪声落在训练噪声模型分布之外。
- **高分辨率训练无济于事**：提升训练网格分辨率改善了后验中心化，但未改善其锐度，说明摊销差距以另一诊断形式再次显现。
- **统计严谨性欠缺**：无误差棒、置信区间、重复运行变异性或显著性检验；真实目标仅 3 个，样本量小。
- **可复现性尚未落地**：论文称"接受后发布可复现工件"，但当前稿件**未提供匿名代码/数据链接或具体复现指令**（NeurIPS checklist 第 5、13 项为 "No"）。
- **应用限制**：方法验证限于 JWST 透射光谱反演场景；作者主张其教训"跨领域"适用（任何模拟器编码了某因素但提议遗漏该因素的 SBI 场景），但未在其他领域实证。
