## 摘要
符号回归（SR）旨在从数据中寻找简洁且可解释的数学表达式，以用于科学方程发现。现有符号回归基准在评估成本与基准有效性之间面临权衡。对大型任务池进行重复评估成本高昂，而紧凑基准缺乏关于任务多样性和算法区分度得以保留的系统性证据。SymbolicArena 为基准蒸馏和动态评估提供了统一基础设施。该框架标准化了 664 个具有可执行真实表达式的异构任务，并将 Full Task Set 蒸馏为 Core50——一个经过验证的、包含 50 个任务的基准。该蒸馏过程在明确的平衡约束下保留了任务覆盖度和算法区分能力。SymbolicArena 将统一执行协议应用于异构符号回归算法，并生成可比较的输出和搜索轨迹。多轴评估刻画数值质量、符号质量和搜索行为。Core50 将评估工作量减少 92.5%，并与 Full Task Set 评估保持一致。实验表明，与替代选择器相比，SymbolicArena 的近似误差降低了 72.6% 至 86.7%，进一步支持了其对 Full Task Set 的保真度。评估揭示了当前符号回归方法在数值拟合与符号恢复之间存在显著差距，表明可靠的方程恢复仍是一个开放挑战。

## Abstract
Symbolic regression (SR) seeks concise and interpretable mathematical expressions from data for scientific equation discovery. Existing SR benchmarks face a tradeoff between evaluation cost and benchmark validity. Repeated evaluation of large task pools is expensive, and compact benchmarks lack systematic evidence of preserved task diversity and algorithm discriminability. SymbolicArena provides a unified infrastructure for benchmark distillation and dynamic evaluation. The framework standardizes 664 heterogeneous tasks with executable ground truth expressions and distills the Full Task Set into Core50, a validated benchmark of 50 tasks. The distillation process preserves task coverage and algorithm discrimination under explicit balance constraints. SymbolicArena applies a unified execution protocol to heterogeneous SR algorithms and produces comparable outputs and search trajectories. Multi Axis Evaluation characterizes numerical quality, symbolic quality, and search behavior. Core50 reduces evaluation workload by 92.5% and maintains agreement with Full Task Set evaluations. Experiments show that SymbolicArena achieves 72.6% to 86.7% lower approximation error than alternative selectors, further supporting its fidelity to the Full Task Set. Evaluation reveals a substantial gap between numerical fitting and symbolic recovery across current SR methods, suggesting that reliable equation recovery remains an open challenge.

- **核心问题**：现有 SR 基准在**评估成本**与**基准有效性**之间存在权衡：
  - 大型任务池覆盖广，但重复评估昂贵；
  - 紧凑基准成本低，但缺乏系统证据表明其保留了任务多样性与算法区分度。
- **整体含义**：论文提出 **SymbolicArena**，一个面向 SR 的统一基础设施，将紧凑基准构造形式化为“基准蒸馏”问题，并配套统一执行协议与多轴评估，目标是在大幅降低评估成本的同时，保持与完整任务集一致的结论。

## 2. 方法论

### 2.1 总体框架
- **两阶段结构**：
  1. **基准蒸馏**：从 664 个标准化任务中蒸馏出 50 任务的 Core50；
  2. **统一评估**：对异构 SR 算法执行统一协议，并进行多轴评估。

### 2.2 Full Task Set 构建
- 从 800+ 候选任务中筛选出 **664 个有效任务**，来源包括 SRSD、LLM-SRBench、SRBench 1.0、SRBench 2025、Keijzer、Nguyen、Korns、Vladislavleva 等。
- 每个任务统一为可执行 schema，包含：变量顺序、目标信息、固定 train/ID/OOD 划分、真实表达式、结构元数据、语义重复组信息。
- 准入要求：真实公式可解析且可执行、变量/常数/算子可解析、划分可生成或可复现、元数据完整。
- 进行表达式归一化、重复控制、结构分析，并固定数据划分供所有算法共享。

### 2.3 Calibration Set 与四探针选择
- **Calibration Set**：200 个任务，用 PySR 与 LLM-SR 作为初始探针，通过 ID/OOD 上的归一化性能差异挖掘信息量高的任务。
  - 高分歧任务 140 个、单侧可解任务 20 个、中等分歧任务 40 个。
- **四探针选择**：
  - 12 个候选算法在 200 个校准任务上评估；
  - 定义校准可用性 \(H_\alpha(a;\tau)=\alpha q(a)+(1-\alpha)[1-b_\tau(a)]\)，默认 \(\alpha=0.5,\tau=100\)；
  - 枚举所有 4 算法子集，要求覆盖至少 3 类搜索范式；
  - 唯一最优为 \(A_4=\{\text{DSO}, \text{PyOperon}, \text{iMCTS}, \text{uDSR}\}\)，覆盖神经策略搜索、进化搜索、结构化搜索。

### 2.4 Core50 蒸馏
- 四探针在 664 任务上以 3 个随机种子运行，记录：
  - 中位 log 误差、IQR、有效输出比例；
  - 结构描述符与响应描述符。
- 定义任务信息量：
  - 区分度 \(Disc_i\) 综合探针误差方差与有效模式熵；
  - 稳定性 \(Stab_i=1-N(u_i)\)；
  - \(Info_i=Disc_i \cdot Stab_i\)。
- 目标函数：
  \[
  J(S)=0.45 Coverage(S)+0.35 MeanInfo(S)+0.20 Balance(S)
  \]
  其中 Coverage 由结构覆盖与响应覆盖组成。
- 约束包括：恰好 50 个任务、每个语义重复组/基名最多 1 个、每子组最多 6 个、难度配额、失败模式限制、每个胜出探针 3–20 个任务等。
- 使用贪心初始化 + 可行单任务交换优化，冻结最佳子集为 Core50。

### 2.5 统一执行协议
- 所有算法通过统一 wrapper 接入，输入训练数据、特征名、目标信息；ID/OOD 测试集与真实表达式保留用于评估。
- 算法环境隔离，子进程执行，统一超时控制，每分钟记录一次 checkpoint。
- 记录最终表达式与搜索轨迹，支持数值、符号与搜索行为分析。
- 正式评估使用 180 分钟预算，每分钟一个 checkpoint。

### 2.6 多轴评估
- 六个维度：
  - **ID / OOD**：数值质量，基于 NMSE 的 clipped log 映射到 [0,1]；
  - **SYM**：符号保真度，优先等价判断，否则用树相似度、变量恢复、算子恢复的组合；
  - **MIN**：
