## 摘要
本文将数据驱动的非线性常微分方程（ODE）发现问题重新表述，并提出了一种新的可解释机器学习（ML）方法。该方法旨在仅从单一状态轨迹数据中学习非线性动力学的未知向量场，无需系统物理学的先验知识。所提方法与传统方法有两个根本区别：1）该方法的表述基于泛函分析与算子理论推导；2）代价函数在函数空间中构造为两个函数之间的距离（积分形式），而非现有机器学习方法中使用的误差离散和。提出了一种增量学习算法，以在线方式处理新训练样本，学习未知向量场。该方法可从受迫和未受迫的自洽与非自洽（或时变）动力系统中发现未知向量场，并能同时发现作为时间函数的未知外力与未知底层动力学。最后给出数值算例以证明所提方法的优势。

## Abstract
In this paper, the problem of data-driven discovery of nonlinear ordinary differential equations (ODEs) is recast, and a new interpretable machine learning (ML) method is proposed. The proposed method aims to learn the unknown vector field of nonlinear dynamics without prior knowledge of the system's physics from only one single state trajectory's data. The proposed method has two fundamental differences with existing methods: 1) the formulation presented in this method is derived based on Functional Analysis and Operator Theory, and 2) the cost function is constructed in the function space as a distance between two functions as an integral, instead of the discrete-sum of errors used in existing ML approaches. An incremental learning algorithm is proposed to learn the unknown vector field to handle new training samples in an online manner. The proposed method can discover the unknown vector field from both forced and unforced autonomous and non-autonomous (or time-varying) dynamical systems. The proposed method is able to simultaneously discover unknown external forces as a function of time and unknown underlying dynamics. Finally, numerical examples are given to demonstrate the advantages of the proposed method.

### 二、论文提出的方法论：核心思想、关键技术细节

**核心思想：**

1. **问题重述与算子视角**：将动力系统$\dot{x}(t) = f(t,x(t)) + F(t)$改写为积分形式：$x(t) = x(t_0) + \int_{t_0}^t f(s,x(s)) ds + \int_{t_0}^t F(s)ds$。在此基础上，从数据构造（9）式的**线性算子序列**$T_k(f)$（算子作用于函数f，而非状态x，这是与经典Hammerstein算子的根本差异）。
2. **函数空间损失与可解释性**：不同于以误差离散平方和为主的现有ML训练模式，FINS在$L^2$函数空间中用内积诱导的范数衡量预测与观测轨迹的构成差异，目标函数形如$\min_{f \in L^2_\varphi} \|T_k(f) - (x - x_0 - \int F)\|^2_{L^2_w}$，即"积分误差"直接作为损失量。由于使用了Hermite多项式（其在$\mathbb{R}^{n+1}$上正交完备），所得的模型为明确显式的多项式近似，实现了可解释性。

3. **Hermite多项式基函数展开**：将未知向量场按Hermite多项式展开，截断有限阶$N_1, N_2, \dots, N_{n+1}$，写为矩阵形式的$f \approx C H(x)$（式（12）—（14）），此处Hermite多项式天然适配全空间数据。
4. **关键的线性代数化简（最优解）**：定理1将原始变分极小化问题化简为求解一个关于$C_k$的二次型问题：$\min_{C_k} C_k^T Q_k C_k + P_k^T C_k + U_k$，其中矩阵$Q_k, P_k, U_k$由数据的数值积分生成。在$Q_k$半正定时（引理/推论1），最优解满足线性方程组$2\tilde{Q}_k C_k^{l*} = -P_k^l$，总计算可分解为$n$个独立的线性方程求解。这使每个动力学分量的学习都可解耦。

5. **增量学习算法（FINS 算法1）**：利用梯形法则以及基于Hermite的积分更新公式（附录E、F），获得了"新数据到达时无需重算全局积分"的矩阵、向量的递推更新公式：新数据只需更新$\tilde{Q}_k$、$P_k^l$、$K_k$等，不需要存储全部历史数据或重新训练，解决了内存限制与数据隐私问题，本质属于"样本增量学习"。

6. **稀疏性促进（FINSS）**：为解决物理系统常见仅少数项主导的问题，将稀疏正则化（L0范数及凸松弛）整合进回归中，并可引入压缩感知算法。

7. **与现有方法的差异**：与NODE需要借助显式ODE求解器不同，FINS直接在函数空间以"积分误差"作为学习目标，无需导数估计，也无需在循环内使用ODE求解器；与SINDy相比，FINS不依赖导数近似；与Koopman方法相比，FINS不预设嵌入函数、不处理流映射而直接作用于向量场本身；与DeepONet类算子学习方法相比，FINS不需要百量级的轨迹数据，单条轨迹便可完成精确辨识。

**整体技术特征：**
- 理论框架：Hilbert空间的严格凸性、算子线性性质、正交基函数逼近，保证了在该函数空间/范数下的可计算性。
- 数值格式：梯形法则作为积分方案，该方法能同时容纳非均匀和均匀采样的数据。
- 普适性：一个统一的框架覆盖自治/非自治、强迫/未强迫系统；对二阶系统通过状态扩张处理；既可单独学习未知向量场，也可同时辨识未知外力和动力学。

- **比较公平性的处理：** 对SINDy给定能含有全部真实项的小候选库（甚至降低搜索范围），但仍旧在部分案例（例如Duffing加噪声时）出现系数误差，且性能对稀疏阈值极其敏感。从公平性看，FINS/FINSS 的使用基函数数量较多，已在文中注明；对某些方法的适用范围（如SINDy只适用于自治、要求导数；KLT要求均匀采样、常输入，Mauroy方法要求输入在两个快照间恒定）也给予了实事求是的比较框定。未包含强外部的不公平结论，可信度较好。
- **数据量对比：** 同其他方法所需的百量级轨迹训练数据相比，FINS只用了“单条轨迹”且往往在少了2~3个数量级的数据（$10^3\sim10^4$级）下表现优秀。这为说明方法的 "仅一个轨迹学习" 结论提供了很强的证据。
- **稳健性统计：** 对于噪声实验注释指出高斯噪声场景下学习结果会和噪声具体实现有关，计算时间的实验有25次独立重复统计均值±标准差的表达。
- **计算时间评估部分**表明其在计算方面较网络类算法有数量级的差异（即快约$10^5$倍数）。

不足之处：
- 仿真实验缺乏大规模真实传感器采集的物理实验数据支撑。
- 对很多非线性常微分方程不满足有限多项式向量场的一般情况下，仅提供了验证性例子而非系统性逼近或归纳证明。
- 没有详细说明SINDy、SymNN/ODENet调参的具体过程，所以对比上的“性能相当”甚至 "更好" 可能有一定的不确定性。
- 方法未涵盖输入-输出数据（输入输出状态）的情况，论文只声称支持全状态测量。因此与只能利用IO数据的常见黑盒建模场景相比，仍有很大空白。
- 没有针对混乱系统做多初始条件、多条轨迹、或含未知测量偏移的一般化试验。

### 六、论文主要结论与发现

1. **全新的公式重构应用**：将ODE发现重述为函数空间中带约束的积分型优化问题，证明该算子$T_k$是线性算子，借此方便地构造了可求解的二次型问题。只要动态数学表示属有限次多项式，FINS可在仅一条状态轨迹、无先验物理、无导数估计的情形下精确复现系统的非线性向量场。

2. **集成与在线学习**：FINS中引入增量更新方案后，当一个新数据点时，矩阵和向量被增量更新（不需要存储完整历史）。因此使其在持续流数据的可扩展学习和数据隐私限制场景中具有实际意义。相比之下，文中的常用方法（SINDy、EDMD等）并不能随时在线导入新样本，普遍不能增量地学习。

3. **统一性**：该方法适用于自治与非自治系统，既能辨识外力固定的情况，也能同时发现任意随时间变化的未知外力（若它是由多项式近似表达的）；该方法对非均匀采样时间数据也是可用的，这是与NODE类似的一个优点。

4. **鲁棒性**：尽管不进行显式求导，但对于高噪声场景仍保持接近无噪声模型的水平。在数值测试中，对于带噪声的Duffing系统，FINS在预测误差方面胜过SINDy和EDMD；而FINSs和SINDy的表现对稀疏阈值明显敏感。

5. **可解释性**：学习后的输出是显式的多项式向量场（基于Hermite多项式基），没有隐层表示，也没有“黑箱”过程。

### 七、优点

1. **非常强的理论基础与物理一致损失**：把代价函数放到函数空间上，用积分距离去度量，比离散点级误差更符合流体/运动学系统的真实、连续、平滑的物理；在数学上直接解决对函数 “逼近” 性能下的最小化问题。
2. **无需修改先验**：不需要预知任何ODE结构（无字典预选嵌入等难题）。
3. **有效克服了SINDy / EDMD / KLT 的适用范围窄的问题**：在统一框架下解决了含输入、非自治（时变）系统，而非像KLT那类方法那样要求严格限制（输入在两采样点之间为常值、需均匀采样）。
4. **天生适合增量更新/持续学习**：推导出精确的增量递推公式，对于在线数据流、内存有限或数据保密的应用非常友好。
5. **低数据需求与初始化自由**：仅需一条轨迹即可完成学习、可以学习非零初始条件，无需多种初始化或暴力搜索。
6. **计算效率远超神经网络类方法**：和 SymNN/ODENet 对比，训练时间快了约5个数量级。在CPU上的算法复杂度也具有良好可解释性。
7. **稀疏促进拓展工作**：将稀疏辨识目标与依赖L0、压缩感知的求解方案结合，让学习结果在精度保持的同时兼具简洁性。
