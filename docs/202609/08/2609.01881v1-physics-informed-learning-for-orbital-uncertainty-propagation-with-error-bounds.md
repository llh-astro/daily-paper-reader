## 摘要
福克-普朗克偏微分方程（FP-PDE）描述了随机动力系统中不确定性的演化。在轨道动力学中，由于非线性运动、高维状态以及大时空域，求解FP-PDE具有挑战性。我们提出了一种物理信息神经网络（PINN）方法，将FP-PDE的解近似为单一时空概率密度，同时量化其最坏情况近似误差。该方法原则上独立于状态坐标和神经网络架构的选择。具体地，为了将概率密度函数（PDF）的性质融入神经网络，我们设计了一种物理信息高斯混合模型（PINN-GMM）。随后，一个伴随误差PINN学习近似误差的动态，并生成随时间变化的界，这些界定义了一个PDF模糊集。该模糊集通过易于处理的线性规划，能够严格计算事件概率的上下界。多个说明性一维示例和若干4D-6D轨道测试案例的数值研究，展示了精确的不确定性传播、正确且信息丰富的误差界，以及相较于常见不确定性传播基线方法（高斯近似、无迹变换和高斯混合模型）的可靠性提升。构建PINN-GMM需要离线训练，因此其计算成本高于基线近似方法；然而，一旦训练完成，单次前向传播即可在亚毫秒时间内（在我们的实现中为0.16毫秒）返回任意时刻的密度。

## Abstract
The Fokker-Planck partial differential equation (FP-PDE) governs uncertainty evolution in stochastic dynamical systems. In orbital dynamics, solving the FP-PDE is challenging because of nonlinear motion, high-dimensional states, and large space-time domains. We develop a physics-informed neural network (PINN) approach that approximates the FP-PDE solution as a single space-time probability density, while also quantifying its worst-case approximation error. This approach is, in principle, independent of the choice of state coordinates and neural network architecture. Specifically, to enforce probability density function (PDF) properties into the neural network, we design a Physics-informed Gaussian mixture model (PINN-GMM). Then a companion error PINN learns the dynamics of the approximation error and yields time-dependent bounds that define an ambiguity set of PDFs. This ambiguity set enables rigorous computation of upper and lower bounds on event probabilities through tractable linear programs. Numerical studies on illustrative 1D examples and several 4D--6D orbital test cases demonstrate accurate uncertainty propagation, correct and informative error bounds, and improved reliability over common uncertainty-propagation baseline methods (Gaussian approximation, unscented transform, and Gaussian mixture model). Constructing the PINN-GMM requires offline training, making it costlier than the baseline approximations; once trained, however, a single forward pass returns the density at any time in sub-millisecond time $(0.16~\mathrm{ms}$ in our implementation).

- 轨道不确定性传播通常建模为随机微分方程（SDE），其精确不确定性演化由 Fokker–Planck 偏微分方程（FP-PDE）控制。
- 直接求解 FP-PDE 面临三重困难：
  - 轨道动力学高度非线性；
  - 状态维度高（典型 4D–6D）；
  - 时空域规模大（数小时乃至更长传播周期）。
- 传统不确定性传播方法大体分两类：
  1. 高斯近似（GA）、无迹变换（UT）、高斯混合模型（GMM）等参数化近似传播方法，速度快但缺乏对近似误差的严格量化；
  2. 直接数值求解/近似 FP-PDE 的方法（如 Galerkin 投影、张量分解），精度可提升但计算开销大、无严格误差界，且可扩展性受限。
- 论文的核心目标：以物理信息神经网络（PINN）直接学习 FP-PDE 的“单一时空概率密度解”，并同时给出可验证、时间相关的**最坏情况误差界**，从而在传播精度、可靠性和推理效率之间取得更好的平衡。
- 该工作强调“已知误差界的模型”优于“精度未知而可能误导决策的模型”，尤其对轨道交会评估等安全关键应用意义重大。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 核心框架

- 待求解问题表述为 FP-PDE：
  - \(\mathcal{D}[p(x,t)] = 0\)，初值 \(p(x,0)=p_0(x)\)。
  - 希望训练一个 PINN \(\hat{p}(x,t)\) 逼近真解 \(p(x,t)\)，并构造误差界 \(B(t)\)，满足：
    \[
    \sup_{x\in X}|p(x,t)-\hat{p}(x,t)|\le B(t)
    \]
- 学习分两阶段：
  1. 训练主网络 \(\hat{p}\) 逼近真密度；
  2. 训练伴随误差网络 \(\hat{e}\)，其动态由误差 PDE 控制：
     \[
     \mathcal{D}[e] + \mathcal{D}[\hat{p}] = 0,\quad e(x,0)=p_0(x)-\hat{p}(x,0)
     \]
  由此按 \(B(t)=2\max_{x\in X}|\hat{e}(x,t)|\) 构造时变误差界。

### 2.2 坐标选择

为缓解高维大时空域的样本稀释问题，论文提出多种坐标变换策略：

- 旋转球坐标：减小计算域并消除整体旋转导致的快速变化；
- 平根数坐标：在无摄动开普勒问题下实现解析解或准解析传播；
- 参考轨迹相对坐标：将学习任务从 \(p(x,t)\) 转移到 \(p(\delta x,t)\)，利于局域化分布；
- 广义映射坐标：通过 Itô 引理推导在隐空间中的 SDE，并与编码器–解码器结构结合。

### 2.3 PDF 表示：PINN-GMM

- 标准 MLP 难以显式保证 PDF 的非负性与归一性。
- 提出时间条件的物理信息高斯混合模型（PINN-GMM）：
  \[
  \hat{p}(x,t)=\sum_{i=1}^{K} w_i(t)\mathcal{N}(x;\mu_i(t),\Sigma_i(t))
  \]
  混合权重、均值、协方差（Cholesky 分解）均由以时间为输入的神经网络输出。
- 额外设计：
  - 固定编码器（白化变换）提升训练条件；
  - 权重使用 logits + softmax，并加入小混合系数 \(\alpha\) 防止分量坍缩；
  - 任意时刻输出均为合法 PDF，且可得到解析边际密度。

### 2.4 事件概率上下界

- 由 \(\hat{p}\) 和误差界 \(B(t)\) 构造 PDF 模糊集：
  \[
  \mathcal{P}(\hat{p}, B, t)= \{p: |p-\hat{p}|\le B(t), p\ge0,\int p dx=1\}
  \]
- 将事件概率 \(P(x\in X_{\text{event}},t)\) 的上/下界计算转化为带区间约束的线性规划（LP）。
- 借助高斯混合的凸性/不等式性质，将每个网格单元上 \(\hat{p}\pm B\) 的极值计算转化为凸二次规划（最小值）与凸包顶点搜索（最大值），使 LP 可高效求解（Algorithm 1）。

## 6. 论文的主要结论与发现

- 将轨道不确定性传播视为学习 FP-PDE 单一时空解是有前景的新路径：在获得一定离线训练代价后，PINN-GMM 能以毫秒级前向推理返回任意时刻全状态密度。

- 坐标选择与表示结构对高维训练成功至关重要：旋转球坐标与编码器显著改善训练收敛性；均匀采样、无编码器、无 PDF 属性的 MLP 在轨道高维问题中极易失败。
- 尽管 PINN-GMM 训练开销更大，其作为可验证误差界的传播工具比无误差量化的传统方法更能保障安全关键分析。

## 8. 不足与局限

- 可扩展性边界尚不明确：
  - 论文只在最多 6D 状态上验证；更高维（如完整的 \(J_2\) 轨道集合、考虑星历摄动）或更长传播天数（一天或多天）未证明；
  - 作者自述误差界可能在更长时域上增长，泛化到多天轨道仍待研究。
- 方法依赖 PDP well-posed 与连续可微动态假设：
  - 无法直接处理脉冲推力、轨道机动等非光滑/非连续动态；若存在 \(t_{\text{imp}}\) 处脉冲，就不能在整个时域内用一个 FP 解描述。
- \(K_{\text{GMM}}\) 选择目前为启发式（文中明确说明“无系统规则”），需要通过尝试和观察误差界决定，初始猜测可能影响可复现性。

- 参考真值的构造存在近似偏差：
  - 用拟合的有限 GMM 估计 Monte Carlo 样本密度，可能会平滑掉强非高斯细节；
  - 对高维密度用 MC 拟合出的参考本身并不精确，可能低估或模糊真实误差。
- 计算成本不平衡：
