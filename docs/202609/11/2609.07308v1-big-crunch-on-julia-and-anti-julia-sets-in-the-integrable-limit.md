## 摘要
Julia 集由混沌系统中排斥周期点的闭包定义。为什么这种结构不出现在可积系统中？在本文中，我们通过证明周期方程发散点闭包的存在性来回答这一问题，并将其命名为“反 Julia 集”。我们还将取闭包之前的集合分别称为前 Julia 集与前反 Julia 集。我们通过引入实形变参数 $a$，考虑一个在可积与非可积动力学之间插值的复映射，来说明这一转变机制。对于 $0<a\le 1/2$，我们证明 Julia 集与反 Julia 集在复平面上重合，尽管前 Julia 集与前反 Julia 集仍完全不相交。在可积极限 $a\to 0$ 处，这两个对偶结构经历临界碰撞并随后湮灭，令人联想到宇宙学中的大挤压。另一方面，当 $1/2<a<1$ 时，前反 Julia 集的边界包含 Julia 集。我们解析地刻画了这些现象，尤其关注前反 Julia 集在趋近可积极限时的渐近行为，并提供数值可视化，以阐明这一大挤压现象的潜在机制。

## Abstract
The Julia set is defined by the closure of repelling periodic points in chaotic systems. Why does this structure not appear in integrable systems? In this paper, we address this question by demonstrating the existence of the closure of divergences of the periodic equations, which we designate as the "anti-Julia set." We also call the sets before taking the closures the pre-Julia and pre-anti-Julia sets, respectively. We illustrate the transition mechanism by considering a complex map that interpolates between integrable and non-integrable dynamics, by introducing a real deformation parameter $a$. For $0<a\le 1/2$, we show that the Julia set and the anti-Julia set coincide in the complex plane, although the pre-Julia and pre-anti-Julia sets remain completely disjoint. At the integrable limit $a\to 0$, these two dual structures undergo a critical collision and subsequent annihilation, reminiscent of a cosmological Big Crunch. When $1/2<a<1$, on the other hand, the boundary of the pre-anti-Julia set includes the Julia set. We analytically characterize these phenomena, focusing in particular on the asymptotic behavior of the pre-anti-Julia set as it approaches the integrable limit, and provide numerical visualizations that elucidate the underlying mechanisms of this Big Crunch phenomenon.

## 2. 方法论

- **核心思想：用一族形变映射把可积与混沌连续连接起来，并同时对偶地追踪周期点与预极点。**
- **关键对象——形变 Logistic 映射（DLM）**：
  - 在三条约束下唯一确定：(i) a=0 退化为可积 Möbius 映射；(ii) a=1 恰为混沌 Logistic 映射；(iii) 固定点 0 与 1−1/μ 以及原点乘子 μ 与 a 无关。
  - 显式形式：$z \mapsto f_a(z)=\dfrac{\mu z\,(1-az)}{1+\mu(1-a)z}$。
  - 由 Saitoh–Saito–Shimizu（1995, 1996）在 KP 梯子背景下引入，唯一性使其成为研究该转变的"必然选择"。
- **对偶集合的定义**：
  - 将 n 次迭代写为 $f_a^{(n)}(z)=\mu^n z\,N_a^{(n)}(z)/D_a^{(n)}(z)$，$a\to0$ 时趋于 Möbius 迭代。
  - 周期条件约化为有理方程 $A_a^{(n)}(z)/D_a^{(n)}(z)=0$（已剥离固定点因子 $X(z)=\mu z-\mu+1$）。
  - **前 Julia 集** $P_a^{(n)}=\{z: A_a^{(n)}(z)=0\}$（有限周期点）；**前反 Julia 集** $Q_a^{(n)}=\{z: D_a^{(n)}(z)=0\}$（预极点，n 步后映到 ∞）。二者的闭包分别为 Julia 集与**反 Julia 集**。
  - 对 $a\neq 0$，$A_a^{(n)}$ 与 $D_a^{(n)}$ 互素，故 $P_a^{(n)}\cap Q_a^{(n)}=\varnothing$。
- **渐近配对机制**：
  - 对根消去参数 a，得到复平面中支配轨迹的**代数曲线**；配对点满足 $\lim_{a\to0}p_j(a)=\lim_{a\to0}q_j(a)=:z_j^*$，在该点分子分母同时为零。
  - 给出递推关系（式 (12)(13)），说明 $D_a^{(n+1)}$、$A_a^{(n+1)}$ 与 $D_a^{(n)}$、$A_a^{(n)}$ 的强关联。
- **Big Crunch 的代数机制（核心结果）**：
  - 将分子、分母按碰撞对与残余因子分解：$A_a^{(n)}=R_a^{(n)}\prod(z-p_j)$，$D_a^{(n)}=S_a^{(n)}\prod(z-q_j)$。
  - $a\to0$ 时生成次数为 $2^{n-1}-1$ 的**公共因子**，在有理函数中被整体代数消去（式 (16)），剩余 $R_0^{(n)}$、$S_0^{(n)}$ 恢复出可积的 $f_0^{(n)}$。
  - 碰撞残留为 **IDP**：$z_k^*=-\dfrac{1}{\sum_{m=1}^{k}\mu^m}$，$k=1,\dots,n-1$，其退化重数为 $2^{n-k-1}$。
  - 论证思路：IDP 是分子分母同时为零的奇异点，故前 Julia 集的退化必然牵动极点结构；从 IDP 重启映射后，经"奇异点约束"迭代生成各周期的连续 IVPP。
- **数值方法（算法流程）**：
  - 用同一逆映射 $z_{i+1}=f_a^{(-1)}(z_i)$ 做**确定性全树展开**，第 i 步产生 $2^i$ 个点；两个集合仅初始值不同：前 Julia 集从有限排斥不动点 $z_0^{(J)}=1-1/\mu$ 出发，前反 Julia 集从 ∞（首次逆迭代后为 $-1/[\mu(1-a)]$）出发。
  - 求解二次方程 $a z_{i+1}^2-(1-(1-a)z_i)z_{i+1}+z_i/\mu=0$ 时，标准求根公式在小根上会产生**灾难性抵消**；作者引入残差 $R_i=1-(1-a)z_i$ 与带符号中间量 $T_i=\tfrac12(R_i+\mathrm{sgn}(\Re R_i)\sqrt{R_i^2-4az_i/\mu})$，将两分支写为 $z_{i+1}=T_i/a$（plus）与 $z_i/(\mu T_i)$（minus），从而把误差压到机器精度（≈10⁻¹⁶）。
  - 拒绝使用随机逆迭代法（RIIM），因为其破坏严格双射配对、无法分辨 $O(a)$ 的微小间隙。

## 6. 主要结论与发现

- **反 Julia 集的定义与地位**：反 Julia 集是周期方程发散点（预极点）闭包，与 Julia 集构成同一映射内的对偶结构，二者在动力学意义上并不等同。
- **参数分区行为**：
  - 对 $0<a\le1/2$（∞ 为排斥不动点，乘子 $\lambda_\infty=1-1/a$，与 μ 无关），Julia 集与反 Julia 集**作为点集重合**，尽管它们的前集 $P_a^{(n)}$ 与 $Q_a^{(n)}$ 除 ∞ 外完全不相交。
  - 对 $1/2<a<1$（∞ 吸引），前反 Julia 集不在 Julia 集上，且 $J(f_a)\subsetneq \partial O_a^-(\infty)$，即前反 Julia 集边界包含 Julia 集；此时两结构无从碰撞。
- **Big Crunch 机制**：a→0 时，无穷多排斥周期点与其对偶预极点沿代数曲线成对汇聚，产生次数 $2^{n-1}-1$ 的公共因子并被整体代数消去，混沌不变量集从相空间"湮灭"，完成向可积态的转变。
- **湮灭残留 = IDP**：$z_k^*=-1/\sum_{m=1}^k\mu^m$（$k=1,\dots,n-1$），退化重数 $2^{n-k-1}$；这些同时零点作为奇异位点，成为可积规则周期结构（IVPP）的代数来源。
- **数值可视化**：证实 a≠0 时存在 $O(a)$ 的严格双射间隙（需无限分辨率才能看出不重合），a→0 时该间隙系统塌缩，a=0 时两集合同时退化为同一组 IDP；相角 θ 的变化会引发复杂的拓扑重联，但"同 a 不相交"这一核心机制不变，说明退化是内蕴性质。
- **误差结论**：稳定化求根公式把误差控制在机器精度量级；前 Julia 集重构误差集中在 ~10⁻¹⁶，前反 Julia 集峰值在 ~10⁻¹²（对应 N=15 时前向映射最大放大 $2^{15}\approx3.3\times10^4$），在 PC 可执行深度（N≤24）内误差不足以造成视觉伪影。
