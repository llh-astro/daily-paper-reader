## 摘要
直接成像系外行星的光度变化同时编码了持久表面特征与云等时变现象的信息。我们提出混合自旋-轨道层析成像，一种从多波段光度变化中同时反演多个静态分量和单个动态分量及其反射光谱的方法。该方法通过在前向模型中引入一个时间相关分量，将光谱解混与动态自旋-轨道层析成像相结合。我们对静态表面分布采用稀疏正则化，对反射光谱采用体积正则化，并对动态分量采用Kronecker和核正则化。将该方法应用于一个玩具地球模型，我们成功恢复了静态表面分布以及单个时间相关云分量。此外，我们将该方法应用于DSCOVR/EPIC对地球的观测，反演出一个与真实云分布一致的动态分量，以及可大致解释为海洋、植被和陆面的分量。相对于静态自旋-轨道解混，混合模型显著降低了多波段光变曲线的残差离散度，表明显式处理动态分量能够改进基于颜色变化的全球制图。这些结果为同时反演静态与动态行星分量迈出了一步，同时凸显了对更物理的云-表面掩膜模型和不确定性量化的需求。

## Abstract
Photometric variability of directly imaged exoplanets encodes information on both persistent surface features and time-variable phenomena such as clouds. We present Hybrid Spin-Orbit Tomography, a method that simultaneously retrieves multiple static components and a single dynamic component, together with their reflection spectra, from multiband photometric variability. The method integrates spectral unmixing and dynamic spin-orbit tomography by introducing a time-dependent component into the forward model. We employ sparse regularization for static surface distributions, volume regularization for reflection spectra, and a Kronecker-sum kernel regularization for the dynamic component. Applying the method to a toy Earth model, we successfully recover static surface distributions together with a single time-dependent cloud component. Furthermore, we apply the method to DSCOVR/EPIC observations of Earth and retrieve a dynamic component consistent with real cloud distributions, together with components broadly interpretable as oceans, vegetation, and land surfaces. Relative to static spin-orbit unmixing, the hybrid model substantially reduces the residual scatter of the multiband light curves, demonstrating that explicit treatment of dynamic components improves global mapping from color variability. These results provide a step toward the simultaneous retrieval of static and dynamic planetary components, while highlighting the need for more physical cloud-surface masking models and uncertainty quantification.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：未来 Habitable Worlds Observatory（HWO）等任务将直接成像并表征潜在宜居类地系外行星。除反射光谱外，时间分辨多波段光度测量可探测行星自转、轨道运动及表面非均匀性（海洋、植被、陆地等）。
- **已有方法**：
  - 自旋-轨道层析（SOT）：从单波段光变重建二维行星地图，但假设表面静态。
  - 自旋-轨道解混（SOU）：结合 SOT 与光谱解混，同时反演静态表面分布和反射光谱，但仍假设观测期内所有分量静态。
  - 动态 SOT：可反演时变地理，但主要针对单波段或主成分图，未显式分离空间与光谱信息。
- **核心问题**：真实类地行星存在云等动态分量，会污染静态反演，导致光谱与地图退化、光变残差偏大。因此需要一种能**同时反演多个静态分量、单个动态分量及其反射光谱**的方法。
- **整体含义**：论文提出 Hybrid Spin–Orbit Tomography（混合自旋-轨道层析），将 SOU 的光谱扩展与动态 SOT 的时间扩展结合，向“静态+动态行星分量联合反演”迈出一步，并指出未来需更物理的云-地表掩膜模型与不确定性量化。

## 2. 方法论

### 核心思想
- 在前向模型中显式加入一个时间相关动态分量，同时估计：
  - \(N_k\) 个静态表面分布 \(A\) 及其反射光谱 \(X\)；
  - 1 个动态分量分布 \(C\) 及其反射光谱 \(x_C\)。
- 观测数据矩阵 \(D\) 的前向模型为：
  \[
  D = (W \odot C)\mathbf{1}_{N_j}x_C^\top + WAX
  \]
  其中 \(W\) 为已知设计矩阵（由观测几何、光照与可见区域决定），\(\odot\) 为 Hadamard 积，\(C\) 为“时间 × 表面像素”的动态地理矩阵。

### 关键技术细节与正则化
- **非负约束**：\(C \ge O,\ x_C \ge 0,\ A \ge O,\ X \ge O\)，来源于 NMF 光谱解混假设。
- **静态表面丰度 \(A\)**：
  - \(\ell_1\) 范数促进空间稀疏；
  - TSV（Total Squared Variation）正则化平滑相邻像素边界、抑制噪声。
- **反射光谱 \(X\) 与 \(x_C\)**：
  - 体积正则化 \(\det(\tilde X \tilde X^\top)\)，其中 \(\tilde X = [x_C^\top; X]\)，用于缓解光谱解混退化。
- **动态分量 \(C\)**：
  - \(\ell_1\) 稀疏正则化；
  - **Kronecker 和核正则化**：
    \[
    \mathrm{vec}(C)^\top(\lambda_S K_S^{-1} \oplus \lambda_T K_T^{-1})\mathrm{vec}(C)
    \]
    空间核 \(K_S\) 用 RBF，时间核 \(K_T\) 用 Matérn-3/2，可独立控制空间与时间正则强度。
  - 论文指出 Kronecker 积核只有单一幅度参数，无法独立控制时空正则，故采用 Kronecker 和核更有效。

### 优化与算法流程
- 最终优化问题为最小化：
  \[
  Q = F + R_A + R_{\tilde X} + R_C
  \]
  其中 \(F\) 为 Frobenius 范数残差，\(R\) 为上述正则项。
- 使用**块坐标下降**：分别对 \(C\)、\(x_C\)、\(\hat a_k\)、\(\check x_k\) 求解子问题并迭代更新。
- 子问题用**近端梯度法**：
  - 更新 \(x_C\)、\(\check x_k\) 用 APG+restart（Nesterov 加速近端梯度）；
  - 更新 \(C\)、\(\hat a_k\) 用 MFISTA（单调快速 ISTA），保证目标函数单调下降。
- 附录给出贝叶斯解释：Kronecker 积核对应高斯先验；Kronecker 和核先验可解释为两个高斯先验的乘积。
