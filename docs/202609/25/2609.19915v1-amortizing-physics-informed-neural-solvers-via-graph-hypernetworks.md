## 摘要
将物理信息神经网络（PINNs）摊销到相关 PDE 上，需要向可复用求解器描述每个方程。系数向量将数值参数编码到预定义槽位中，使算子和跨场分配保持隐式。我们在算子图中显式表示这些关系，其中节点表示场、导数、项和残差，系数保留为项属性。图超网络生成对角码，用于初始化针对每个目标方程元训练得到的因子化 PINN。元训练和目标特定自适应使用控制方程和指定条件，无需解标签。我们在固定自适应预算下，按求解精度比较系数向量、基于 DeepSets 的项集合和图条件化。在标量对流-扩散-反应问题中，两种基于项的描述符均提高了高反应精度，性能相似。在双场 Fisher-KPP 中，元训练见到未耦合和单向系统；在对未见过的双向耦合进行 3,000 步自适应后，图的平均最终误差比项集合低 35.7%，比系数向量低 67.7%。在固定结构的电容耦合等离子体模型中，系数向量表现最好。这些结果支持用显式方程关系扩展系数条件化，以实现基于物理的求解器自适应。

## Abstract
Amortizing physics-informed neural networks (PINNs) across related PDEs requires describing each equation to a reusable solver. Coefficient vectors encode numerical parameters in predefined slots, leaving operator and cross-field assignments implicit. We make these relationships explicit in an operator graph, with nodes for fields, derivatives, terms, and residuals and coefficients retained as term attributes. A graph hypernetwork generates diagonal codes that initialize a meta-trained factorized PINN for each target equation. Meta-training and target-specific adaptation use governing equations and prescribed conditions without solution labels. We compare coefficient-vector, DeepSets-based term-set, and graph conditioning by solution accuracy within a fixed adaptation budget. In scalar convection-diffusion-reaction problems, both term-based descriptors improve high-reaction accuracy, with similar performance. In two-field Fisher-KPP, meta-training sees uncoupled and one-way systems; after 3,000 adaptation steps on unseen two-way coupling, the graph's mean final error is 35.7% below the term set and 67.7% below the coefficient vector. In a fixed-structure capacitively coupled plasma model, the coefficient vector performs best. These results support extending coefficient conditioning with explicit equation relationships for physics-based solver adaptation.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：如何将物理信息神经网络（PINNs）摊销到一族相关偏微分方程（PDE）上，使一个可复用求解器能够快速适应新方程实例。现有系数向量方法将数值参数填入预定义槽位，但**算子组合与跨场分配关系是隐式的**，超网络无法直接感知“哪个场影响哪个方程”“哪些项组合在一起”等结构信息。
- **研究动机**：耦合 PDE 中，交互强度与所连接的变量共同构成方程语义。例如，`u` 方程中的源项 `κv` 与 `v` 方程中的源项 `κu` 描述相反的耦合方向，即使系数 `κ` 相同，含义也不同。仅靠系数向量难以区分这类结构差异。
- **整体含义**：论文提出用**算子图**显式表示场、导数、项与残差之间的连接关系，并让图超网络据此生成 PINN 的初始化配置。核心假设是：**关系条件化的价值取决于方程族中“什么在变化”**——当跨场耦合模式变化时，图条件化优势明显；当结构固定、仅系数变化时，系数向量反而更优。

## 2. 方法论：核心思想、关键技术细节与流程

- **核心思想**：将每个 PDE 残差表示为算子图，节点包括场、导数、项、方程残差；系数保留为项节点的属性。图超网络读取该图，预测因子化 PINN 每层的对角码，形成方程条件化初始化；再通过物理残差进行目标特定自适应。
- **算子图构建**：
  - 每个加性单项式为一个项节点，携带标量系数和场/导数因子元组。
  - 连接关系：场 → 其导数；因子 → 包含它的项；项 → 目标残差。
  - 节点特征记录：节点种类、场身份、导数阶数、系数符号、对数幅值、元数（因子数量）等。
  - 耦合系统中，目标连接显式标识每个项进入哪个方程。
- **图超网络与 PINN 配置**：
  - 节点特征经嵌入后，进行多轮消息传递：`h^{k+1}_i = h^k_i + σ(W_self h^k_i + W_neigh Σ_j â_ij h^k_j)`，其中 `σ` 为 GELU，`â_ij` 为对称化、自环、行归一化后的邻接权重。
  - 经过 K 轮后，对场 `f` 的读出网络 `ρ` 预测各层码：`s^ℓ_f = ReLU(A_ℓ r_f + b_ℓ) ∈ R^w`。
  - 码用于配置因子化 PINN：`W^ℓ_f = C_ℓ diag(s^ℓ_f) R_ℓ`，其中 `C_ℓ, R_ℓ` 为共享学习基，`w` 为隐藏宽度。超网络只预测 `w` 维对角码，而非完整 `w×w` 权重矩阵。
- **训练与部署流程**：
  - **元训练阶段**：采样 PDE 实例与配点，联合优化超网络、共享基、骨干网络参数。目标函数为方程残差平方与软初始/边界惩罚的加权和；硬约束通过坐标与输出变换实现。**不使用解标签**。
  - **部署阶段**：对每个目标方程，调用一次训练好的超网络得到初始码，复制元训练骨干，然后仅用目标物理目标更新码与骨干参数；超网络保持固定。Fisher–KPP 在自适应中保留 ReLU 参数化，CDR 与 CCP 直接优化对角项。
- **描述符基线**：
  - **系数向量**：MLP 将预定义系数布局映射为码；缺失项零填充，可隐含编码耦合分配。
  - **DeepSets 项集合**：独立嵌入每个项 token 后均值池化；Fisher–KPP 中省略源场与目标方程分配，CCP 中按残差/场分组。
  - **算子图**：显式包含连接与系数属性。

## 6. 主要结论与发现

- **高反应 CDR**：
  - 两种基于项的描述符（项集合与算子图）均显著优于系数向量。五到二协议下，项集合与图分别降低平均误差约 **85.1%** 与 **85.4%**；全七协议下误差进一步降低，种子间波动减小。
  - 图与项集合性能接近，**没有一致优势**。该标量家族支持基于项的条件化，但图未超越集合。
- **双场 Fisher–KPP（未见双向耦合）**：
  - 算子图取得最低平均最终误差：`(1.786 ± 0.318)×10^{-3}`。
  - 相比项集合低 **35.7%**，相比系数向量低 **67.7%**，相比从零开始低约 **81.5%**。
  - 图在 H1–H4 每个留出案例和每个场上均一致更低；oracle-best 评价下排序保持。
  - 所有权感知项集合控制未能缩小与图的差距。
  - 消息传递轮数从 2 增至 5，最终误差进一步降低 **26.6%**（固定参数数量）。
- **CCP（固定结构、系数变化）**：
  - 系数向量表现最好（最终 `rel L2 = 0.1396 ± 0.0347`），优于项集合（0.2361）与算子图（0.2483），但图仍优于从零开始（0.4866）。
  - 表明物理耦合本身不足以确保图条件化优势。
- **总体结论**：
  - 关系条件化的价值取决于**方程族中变化的部分**：当跨场耦合模式变化时，显式图表示带来显著优势；当结构固定、仅系数变化时，系数向量可能更优。
  - 基于项的条件化在高反应标量 CDR 中有效，图与集合相当。
  - 摊销初始化能显著减少达到目标精度所需的优化步数（CDR 留出结构上，图中位数从 2200 步降至 600 步）。

## 7. 优点

- **表示创新**：将方程表示为算子图，显式编码场、导数、项、残差之间的连接关系，同时保留系数作为项属性，兼顾数值与结构信息。
- **物理-only 训练**：元训练与自适应均不使用解标签，仅依赖控制方程与指定条件，符合 PINN 的物理约束范式。
- **公平比较**：在同一家族内严格控制骨干架构、参数数量、优化预算、采样策略与 PDE 分布，描述符对比具有可比性。
- **消融系统
