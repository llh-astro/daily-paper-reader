## 摘要
直接从轨迹数据比较非线性动力系统仍然具有挑战性，因为有限时间轨迹表示通常依赖于坐标。受近期针对线性系统的行为子空间方法的启发，本文利用多次滚动轨迹数据为非线性随机系统引入了一种 Koopman-行为距离。状态测量通过一个公共可观测字典提升，并使用 Grassmannian 距离比较主导提升行为子空间，无需显式识别 Koopman 算子。我们建立了坐标不变性、在精确提升闭包下与近期提出的线性行为距离的联系，以及对近似闭包的鲁棒性。数值示例展示了坐标不变性和参数判别。

## Abstract
Comparing nonlinear dynamical systems directly from trajectory data remains challenging because finite-horizon trajectory representations are generally coordinate dependent. Motivated by recent behavioral subspace approaches for linear systems, this paper introduces a Koopman-behavioral distance for nonlinear stochastic systems using multi-rollout trajectory data. State measurements are lifted through a common observable dictionary, and dominant lifted behavioral subspaces are compared using Grassmannian distances without explicit Koopman operator identification. We establish coordinate invariance, connection with recently proposed linear behavioral distances under exact lifted closure, and robustness to approximate closure. Numerical examples demonstrate coordinate invariance and parameter discrimination.

## 1. 论文的核心问题与整体含义

- **核心问题**：直接从轨迹数据比较两个非线性动力系统是否“相同”或“相似”非常困难。对于线性时不变（LTI）系统，可以利用 Hankel 矩阵的列空间表示有限时域行为，并借助 Grassmannian 距离在子空间之间度量差异；然而非线性系统在原始状态坐标下不具有有限维线性表示，且轨迹行为对坐标变换敏感，导致经典的“行为距离”无法直接推广。
- **研究动机**：现有非线性系统比较方法多依赖于显式估计 Koopman 算子、谱或概率分布，计算复杂且在数据驱动场景中不便直接使用；而模型验证、故障检测、数字孪生等应用需要一种仅基于轨迹数据、不需要重建完整模型、且对坐标表示具有鲁棒性的可比度量。
- **整体含义**：论文提出一种 **Koopman-行为距离**，将非线性系统通过可观测字典提升到高维特征空间，使行为子空间的几何比较变得有意义，从而把线性系统行为理论的思想推广到非线性随机系统。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 核心思想
- 利用 Koopman 算子理论中的“提升”（lifting）思想：将状态 \(x_t\) 通过共同的可观测字典 \(\psi\) 映射到高维提升状态 \(z_t = \psi(x_t)\)。在理想情况下，非线性随机系统的演化可以在提升空间中被近似视为线性递归。
- 不显式识别 Koopman 算子，而是直接从多轨迹数据构造**提升的 Hankel 矩阵**，提取其主导左奇异向量张成的子空间，再通过 Grassmannian 距离比较不同系统的行为子空间。

### 关键步骤
1. **多轨迹数据采样**：对系统 \(x_{t+1} = f(x_t, \xi_t)\)（\(\xi_t\) 为外生随机扰动）采集 \(M\) 条独立 rollout，每条长度为 \(T_j\)。
2. **提升**：用公共字典 \(\psi\) 计算提升状态 \(z_t = \psi(x_t)\)。
3. **构造提升 Hankel 矩阵**：对每个 rollout 取长度 \(L\) 的滑动窗口，形成堆叠段 \(Z_t = [z_t^\top, \dots, z_{t+L-1}^\top]^\top\)，收集所有段构造成矩阵 \(H_L(D) \in \mathbb{R}^{NL \times \tau}\)。
4. **降维与行为子空间**：对 \(H_L(D)\) 做 SVD，保留前 \(r\) 个左奇异向量（或按能量阈值选择），定义主导行为子空间 \(B_{L,r}(D)\)。
5. **比较**：对两个数据集对应的子空间计算主角度，进而使用弦距离（chordal）、测地距离（geodesic）或 Procrustes 距离作为 Koopman-行为距离。

### 理论基础 / 理论性质
- **基本不变性**：距离在列重排、可逆列重参数化、公共正交坐标变换下保持不变；但对一般非正交可逆变换不保持主角度。
- **坐标不变性**（定理 1）：若非线性坐标变换 \(y = h(x)\) 为微分同胚，且观测字典按 pullback 方式变换（\(\tilde\psi = \psi \circ h^{-1}\)），则提升后的轨迹段逐点完全相同，因此行为子空间完全一致，距离为零。
- **与线性行为距离的联系**（定理 2）：若提升后的状态满足精确样本闭包 \(z_{t+1} = A z_t\)，则提出的距离精确退化为线性系统行为距离。
- **鲁棒性**（定理 3 / 推论 2）：当闭包有残差 \(z_{t+1} = A z_t + \eta_t\) 时，利用 Wedin 的 \(\sin\Theta\) 定理给出子空间误差界和对距离的扰动界；只要残差范数与奇异值间隙之比很小，距离是鲁棒的。

- **坐标变换**：非线性微分同胚 \(x = h(z) = [z_1, z_2 + c z_1^2]^\top\)，取不同的剪切强度 \(c \in [0, 3]\)。
- **比较对象**：
  - pullback 提升：\(\psi_x(x) = h^{-1}(x) = z_t\)，理论上应与原系统行为一致；
  - 原始状态提升：\(\psi_x^{\text{raw}}(x) = x\)，作为“错误坐标”基线。
- **数据规模**：变化 rollout 数 \(M \in \{5, 20, 50, 100\}\)，每条长度 \(T \in \{60, 100, 180, 350\}\)，窗口 \(L \in \{5, 10, 15\}\)，主导秩 \(r=6\)。

- **比较任务**：给定某个查询质量的轨迹数据集，从五种参考质量的数据库中找出最匹配的质量（最近邻分类）。
- **观测字典**（仅对垂直方向 \(p_z, \dot p_z\) 构造）：
  - \(\psi_{\text{lin}} = [p_z, \dot p_z]\)
  - \(\psi_{\text{elem}} = [p_z, \dot p_z, p_z^2, \dot p_z^2]\)
  - \(\psi_{\text{full}} = [p_z, \dot p_z, p_z^2, p_z \dot p_z, \dot p_z^2]\)
- **参数**：\(r = 12\)，\(T = 200\)，变化 \(M \in \{25, 50, 100, 200, 500, 800, 1000, 1500\}\)，\(L \in \{4, 6, 8, 10, 12\}\)，进行 100 次独立重复试验。
- **评价指标**：最近邻分类准确率、距离中位数，以及识别裕度 \(\mu = d_{\text{true}} - d_{\text{wrong}}\)（负值表示正确识别且越小越好）。

## 6. 论文的主要结论与发现

1. 通过 Koopman 提升能够在高维特征空间构造有限时域行为子空间，并基于 Grassmannian 距离给出两个非线性随机系统之间的数据驱动距离。
2. 当观测字典按 pullback 随坐标变换同步改变时，提出的距离对非线性微分同胚坐标变换具有精确不变性；而直接在原始状态上计算的行为距离会错误地报告不同坐标表示之间的差异。
3. 在精确样本闭包条件下，该距离与线性系统行为距离等价；在近似闭包下，有明确的扰动界保证距离的鲁棒性，该界依赖残差范数与奇异值间隙之比。
4. 数值实验验证：质量参数不同的四旋翼系统能通过该距离正确区分，且增加 rollout 数量会提高分类准确率并增大识别裕度；非线性观测字典比线性字典在有限数据下提供更好的判别能力。
5. 提升坐标系的选择（字典、尺度、维度、窗口长度）直接影响比较质量，但距离的绝对数值仅在同一字典下具有可比性。

## 8. 不足与局限

- **对字典的强依赖**：方法有效性取决于所选用可观测字典能否捕捉系统的本质动力学；论文只给出启发式选择（如多项式特征），缺乏系统化字典构造准则。
- **没有真实系统实验**：所有验证均来自仿真，缺少真实数据的压力测试。
- **缺乏与替代方法的对比**：没有与现有非线性系统比较方法（如 KL 率度量、扩散映射、算子谱距离等）进行定量比较，难以判断相对优势。
- **坐标不变性需要 pullback 配合**：实际中若坐标变换未知，无法构造正确的 pullback 提升，字典改变会导致不同的行为子空间；论文没有讨论如何自动适应未知坐标变换。
- **理论假设较强**：精确样本闭包几乎只在可观测字典恰好满足有限维不变子空间时才成立；实际只能近似，鲁棒性依赖奇异值间隙，若间隙很小则界很差。
- **超参数敏感性未深度分析**：秩 \(r\)、窗口 \(L\)、特征归一化方法的影响只部分涉及（如四旋翼中 \(L\) 的折中），但缺少对 \(r\) 选择的系统研究。
- **距离的解释性有限**：不同字典、不同维度下的距离数值不直接可比，实际应用时需要在完全相同的表示前提下进行，限制了跨系统的通用性。
- **实验维度较低**：没有验证高维混沌系统、大尺度网络或含控制输入的系统，推广性尚待证实。
