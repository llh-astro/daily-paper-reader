## 摘要
符号回归旨在从观测数据中恢复闭式方程，为科学发现提供可解释模型。现有方法难以兼顾灵活的结构搜索与高效推理。基于搜索的方法能够细化表达式结构，但通常依赖昂贵的组合优化并采用随机初始化。预训练神经模型几乎可以即时生成公式，但其预测往往包含符号错误。我们提出MOSAIC-SR，它利用预训练Transformer生成多个初始草图。这些草图在若干有前景的区域中初始化搜索，从而避免在庞大的表达式空间中进行随机起点搜索。每次搜索通过尺度感知的常数优化和局部符号修复，联合恢复结构与常数。我们在带有和不带有虚拟变量的SRSD-Feynman数据集以及六个额外基准上评估MOSAIC-SR。MOSAIC-SR在每个数据集上都取得最高的符号解率，同时在预测精度上位列前二。即使存在无关的虚拟输入，这一优势依然保持。结果表明，学习到的先验能够将搜索聚焦于有前景的方程结构，并且数值优化和符号修复对于方程恢复至关重要。

## Abstract
Symbolic regression aims to recover closed-form equations from observations, providing interpretable models for scientific discovery. Existing approaches struggle to combine flexible structural search with efficient inference. Search-based methods can refine expression structure but often rely on costly combinatorial optimization with random initialization. Pretrained neural models generate formulas almost instantly, but their predictions often contain symbolic errors. We introduce MOSAIC-SR, which uses a pretrained Transformer to propose multiple initial sketches. These sketches initialize searches in several promising regions, avoiding random starts in the vast expression space. Each search jointly recovers structure and constants through scale-aware constant optimization and local symbolic repair. We evaluate MOSAIC-SR on the SRSD-Feynman dataset with and without dummy variables and on six additional benchmarks. MOSAIC-SR obtains the highest symbolic solution rate on every dataset while ranking among the top two methods in predictive accuracy. This advantage persists in the presence of irrelevant dummy inputs. The results show that learned priors can focus search on promising equation structures, and that numerical optimization and symbolic repair are important for recovery.

- **现有方法的两难**：
  - **搜索类方法**（Eureqa、PySR、Operon、GP-GOMEA、AI Feynman 等）可在看到数据后灵活修改结构与常数，但每个新问题都从随机初始化从头开始，需重复发现有用子表达式，组合优化代价高。

- **目标**：用学习到的先验把搜索聚焦到有希望的表达式区域，再用显式搜索完成结构与常数的修复，从而同时兼顾 R² 与符号恢复。

## 2. 方法论：MOSAIC-SR

### 2.1 总体思想
"像拼马赛克一样"——由预训练 Transformer 提出多个**符号草图（sketch）**，MCTS 将变量 token 映射到实际输入，生成若干完整方程，再以它们初始化**并行的局部搜索路径**，交替进行结构编辑与常数重拟合。

### 2.2 预训练数据与表示
- 从含 1–5 个变量（推理时支持最多 10 个）的合成表达式中采样，算子词表为二元 {+,−,×,÷} 与一元 {(·)²,(·)³,sin,cos,exp,log,√·,tan,tanh,arctan}。
- 采用**前缀波兰表示**（如 `x1+sin(x2)` → `(ADD X1 SIN X2)`），算子树可无歧义解析。
- 用 **SymPy 归一化**（如 `3+x+2x+sin(yx)−1 → 2+3x+sin(xy)`），减少等价形式的冗余。
- 每条表达式生成两种序列：**完整序列**（供符号编码器）与**草图序列**（变量/常数叶节点替换为特殊占位 token，作为解码目标）。
- **关键设计**：随机选择输入分布与定义域、采样 200 个点，使同一表达式在不同观测范围下出现；**刻意剔除仿射变换**，因为其引入的尺度与偏移会产生真值中不存在的项，妨碍精确符号匹配。

### 2.3 阶段一：数值–符号对齐（对比预训练）
- **数值编码器**：将每个观测行（输入拼接输出）做逐元素有符号对数变换 φ(a)=sign(a)·log(1+|a|)，输入按**集合**（而非序列）处理；用 Set Transformer（ISAB + PMA 注意力池化）得到集合表示 M_D 与池化表示 z_D。
- **符号编码器**：Transformer 编码器 + 可学习位置嵌入 + 掩码平均池化，得到 z_e。
- **损失**：双向 InfoNCE（CLIP 风格），相似度 s_ij=cos(z_Di, z_ej)/τ，正样本对相对所有负样本对拉近，使数值观测与其生成表达式在共享空间中对齐。

### 2.4 阶段二：草图生成
- 在数值编码器后接自回归 Transformer 解码器，以 teacher forcing 训练生成草图序列。
- 损失 L_CE 为 token 级交叉熵；另设若干轻量预测头估计**粗粒度结构属性**（根节点元数、根算子类别），总损失 L_sketch = L_CE + λ_aux·L_aux，用于把结构信息注入数值表示。

### 2.5 推理流程
1. **草图生成**：随机（nucleus）采样得到多样草图，丢弃重复项与违反前缀语法的序列。
2. **MCTS 补全**：将解码出的变量 token 映射到观测输入，并拟合常数，按训练 NMSE 排序，取前 **24** 个完整方程初始化 **24 条独立局部搜索轨迹**。
3. **尺度感知常数拟合**：对固定结构 e(x;c)，用 Levenberg–Marquardt 从**对数间隔的多个数量级初值**（16 个起点）求解最小二乘，以适应跨越多个量级的物理常数；搜索过程中周期性重拟合。
4. **结构修复**：每条路径迭代替换算子、变量或小子树；若干次变异后重拟合常数并按训练 NMSE（按目标方差归一化）决定是否接受；每条路径执行 **300 次变异尝试**。
5. **选择与化简**：共享 Hall of Fame 保存所有路径的最优候选；用验证集选择——若存在验证 NMSE < 10⁻¹⁵ 的候选，选**算子数最少**者，否则选验证 NMSE 最低者；随后将小常数置零，并把接近常见物理常数的拟合值"吸附"到其符号形式（仅在验证误差仍在容差内时保留）。

### 2.6 架构规模
- Set Transformer 数值编码器（4 个 ISAB 块、256 维、8 头、32 个诱导点、16 个 PMA 种子向量）；符号编码器 6 层、解码器 4 层、隐藏维 256、FFN 1024、dropout 0.1、GELU；词表 45，最大变量数 10，**总参数约 17.4M**，相对轻量。

- **推理预算**：SRSD-Feynman 上每问题 **3600 秒**预算；交叉基准沿用各基线默认预算。
- **未明确说明**：预训练与整体实验的**总 GPU 小时数/墙钟时长未报告**；SRSD-Feynman 上因原论文未报运行时而**未做运行时对比**。
